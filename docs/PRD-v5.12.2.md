# PRD v5.12.2 (UX-8) — 配色深水区优化 + 类玻璃特效

- 输入：对 6 色相 x 明暗共 12 套主题的深度测量 + 玻璃特效对照实验
- 决策：4 项均经问卷确认（见第 3 节）

## 1. 配色深度评估（实测）

### 1.1 品牌色 × 语义色「撞色」矩阵（色相距离 < 30° 视为撞色）

| 主题 | 品牌色 | 撞色项 | 后果 |
|---|---|---|---|
| 金 45 | hsl(45,75%,42%) | warning **19°** | 警告琥珀与品牌金几乎同色，警示性丢失 |
| 蓝 220 | hsl(220,75%,42%) | info **4°** | 信息蓝被当成主色，层级不分 |
| 红 0 | hsl(0,75%,42%) | market-up **0°** / danger **0°** / warning 26° | 涨(红)与品牌红完全同色；危险色无法区分 |
| 绿 140 | hsl(140,75%,42%) | market-down **16°** | 跌(绿)与品牌绿撞色 |
| 紫 270 | hsl(270,75%,42%) | 最小 46° | 最安全 |
| 粉 320 | hsl(320,75%,42%) | market-up 40° / danger 40° | 偏近但未越线 |

根因：--market-up/down/danger/warning/info 是固定色，不随品牌色避让——任何「色相可调 + 固定语义色」体系都会遇到。

### 1.2 品牌色感知亮度不一致

各色相主色固定 hsl(色相,75%,42%)，但相对亮度差 5 倍（黄绿 ≈0.42 / 蓝 ≈0.08）→ 蓝色图标、图表线、描边明显偏暗，主题间观感不齐。
（V5.31 已对「按钮/文字/渐变」用自适应求解器归一，但 --primary-color 本身仍固定。）

### 1.3 非文本对比度（WCAG 1.4.11 口径）

| 项 | 实测（亮/暗） | 门禁 | 结论 |
|---|---|---|---|
| 卡片描边 --qc-border vs 卡片 | 1.28~1.35 / 1.40~1.51 | ≥3（功能性边界） | 偏弱，建议提到 ~2.0 |
| 图表轴线 --chart-axis vs 卡片 | **2.10** / 3.10~3.22 | ≥3 | 亮色不达标 |
| muted 文字 vs 卡片 | 5.77~6.75 / 7.46~7.77 | ≥4.5 | 良好 |

## 2. 玻璃特效可行性评估（实测 A/B/A/B x4 中位数）

| 方案 | 滚动 fps | 最差帧 | 结论 |
|---|---|---|---|
| 浮层玻璃（现状：对话框/下拉/提示） | 60.8 | 17.1ms | **零影响**（浮层不在滚动路径上） |
| 结构层玻璃（侧栏/头部/卡片加 backdrop-filter） | **14.0**（基線 55.0） | **106.5ms**（基线 36.0） | **-75% 帧率，不可作默认** |

原因：backdrop-filter 要求每帧重新采样背后内容；结构层元素在滚动时背后内容持续变化 → 逐帧模糊重建。

可行的替代：**类玻璃**（实底/半实底 + 1px 高光内边 + 轻噪点 + 边缘渐变）——纯 CSS，不重采样背景，性能≈0，观感接近磨砂玻璃。

## 3. 决策记录（问卷确认）

| # | 决策点 | 结论 |
|---|---|---|
| D1 | 品牌色×语义色撞色 | **双通道兜底**：涨跌加 ▲▼ 符号 + 底色深浅，颜色只作辅助（不限制选色自由） |
| D2 | 品牌色感知亮度 | **归一到相对亮度 ~0.18**（复用自适应求解器） |
| D3 | 非文本对比度 | **描边提到 ~2.0:1 + 亮色图表轴线提到 ≥3:1** |
| D4 | 玻璃特效 | **默认只做「类玻璃」（性能≈0），真玻璃仅浮层**；不加结构层真玻璃档 |

## 4. 需求

### FR-5.12.2.1 品牌色感知亮度归一（D2）
- --primary-color / --qc-primary-500/600 按目标相对亮度 0.18 求解（容差 ±0.03），保留色相与足够彩度。
- 验收：6 色相 x 明暗，12 套主色相对亮度落在 0.15~0.21；主色对卡片对比度仍 ≥3:1（大元素）且不破坏既有 AA 项。

### FR-5.12.2.2 涨跌双通道（D1）
- 涨跌数值统一带 ▲ / ▼ 前缀；涨跌底色用语义色 10~14% 混合的浅底（已具备 color-mix 能力）。
- 覆盖：今日一屏池变动 / 策略统计 / 涨跌幅 / 评分变化标记 / 自选与持仓列表。
- 验收：红/绿主题下，仅靠符号与底色即可区分涨跌（灰度截图可辨）。

### FR-5.12.2.3 非文本对比度（D3）
- --qc-border：hsl(h,14%,88%) → hsl(h,12%,80%)（≈2.0:1）；--border-base 同步微调。
- --chart-axis（亮）：hsl 明度加深至对卡片 ≥3:1。
- 验收：脚本实测 12 套均达标；对比度审计仍为 0。

### FR-5.12.2.4 类玻璃样式层（D4）
- 新增 .qc-glass-surface 工具类：半实底 + inset 1px 高光 + 极轻噪点（SVG data-uri，可选）+ 边缘渐变。
- 应用到：卡片头、统计卡、面板、登录品牌区等静态表面；浮层继续用真 backdrop-filter。
- 验收：应用类玻璃后滚动 fps 与基线一致（±3%）；浮层玻璃保留。

## 6. 实施结果（v5.12.2 实测）

| 指标 | 目标 | 实测 |
|---|---|---|
| 主色相对亮度极差（6 色相 x 明暗） | ≤1.4 倍 | **1.02 倍**（亮色 0.179~0.182 / 暗色 0.338~0.344） |
| 涨跌双通道 | 符号+底色可辨 | 今日一屏 ▲ +12 / ▼ -14，语义色 12% 浅底 |
| 卡片描边对比度 | ≥2.0 | **1.90~2.14** |
| 亮色图表轴线 | ≥3.0 | **3.07~3.57** |
| 类玻璃后滚动 fps | ≥53（基线 55） | **60.1**；结构层 backdrop-filter 元素 0 |
| 文本对比度审计 | 0（不回归） | 0 |
| 测试基线 | 9 failed / 3341 passed | **9 failed / 3341 passed** |

实现：`_lumL()` 二分求解明度（主色 0.18 / 500 档 0.26 / 400 档 0.36 / 700 档 0.12，暗色 0.34 / 0.46）；`.today-pool-val`/`.pool-change-val` 浅底 + 模板 ▲▼；中性梯度内 `--qc-border` hsl(h,12,72)、`--chart-axis` hsl(h,12,55)（暗色 30/52）；`.qc-glass-surface` + `.today-hero/.stat-card` 高光浅渐变，rgba 字面量令牌化以通过 components.css 硬编码色门禁。
