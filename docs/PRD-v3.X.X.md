## 2. 产品定位

量化选股日历是一个面向 A 股量化投资者的**决策辅助平台**: 以美林时钟宏观周期判断为纲,
多策略选股信号为目, AI 多模型评估为脑, 定时推送为手, 覆盖"感知 → 信号 → 决策 → 验证 → 协作"全链路。

### 2.1 核心价值主张 (v3.1.0 已实现)

| 能力层 | 现状 | 成熟度 |
|--------|------|--------|
| 感知层 | 美林时钟五维度评分 + 14 条历史周期 (2008 至今 4 轮) | ★★★★☆ |
| 信号层 | 4 策略选股 + 共识榜 + 股票池 + 日/周/月/年视图 | ★★★★☆ |
| 决策层 | 8+ 模型串行评估 + 技术指标注入 + 智能问股 (SSE 流式) | ★★★★☆ |
| 验证层 | 回测 API 完整, 前端 UI 缺失 | ★★☆☆☆ |
| 协作层 | 飞书推送 + 三组权限 + 多用户 | ★★★☆☆ |

### 2.2 用户画像

| 角色 | 场景 | 核心诉求 |
|------|------|----------|
| 独立量化投资者 (主要) | 每日看选股信号, AI 辅助决策 | 数据新鲜、评估可信、操作高效 |
| 团队管理者 (次要) | 多用户共用, 分配权限 | 可审计、可追踪、数据可靠 |
| 技术集成方 (远期) | 对接自有系统 | 开放 API、文档完善 |

### 2.3 产品目标 (v3.X 系列)

1. **体验达标**: UI 从"能用"到"好用" (v3.2.0)
2. **数据可靠**: 不丢、不坏、可恢复 (v3.3.0)
3. **可运维**: 部署后看得见、查得到、告得响 (v3.4.0)
4. **AI 自动**: 从单股问答到组合级智能 (v3.5.0)
5. **架构健康**: 单文件瘦身, 可维护 (v3.6.0)
6. **触达广泛**: 多渠道通知 + 开放集成 (v3.7.0)
7. **移动可用**: 手机真机可用 (v3.8.0)
8. **开放生态**: 文档 + API Key + 插件 (v3.9.0)

## 3. 全局需求 (所有 v3.X 版本适用)

### 3.1 非功能需求

| 编号 | 需求 | 验收标准 |
|------|------|----------|
| NFR-1 | 性能: API 响应 | 常规接口 P95 < 500ms, 数据接口 P95 < 2s |
| NFR-2 | 性能: 前端加载 | 首屏 < 3s (4G 网络), 骨架屏覆盖所有数据区块 |
| NFR-3 | 安全: 认证 | JWT + bcrypt 保持, 密钥加密存储保持 |
| NFR-4 | 安全: 前端 | CSP/HSTS 头保持, 不引入新 npm 依赖 |
| NFR-5 | 可用性: 数据 | 任何操作不丢失已有数据 (备份先行) |
| NFR-6 | 兼容性: 浏览器 | Chrome/Edge 最新 2 版 + Safari 最新版 |
| NFR-7 | 兼容性: 宽度 | 375/768/1440px 三档无溢出无遮挡 |
| NFR-8 | 可访问性 | 7 主题下文字对比度 ≥ 4.5:1 (WCAG AA) |
| NFR-9 | 可维护性 | 单次改动 ≤ 50 行, 每改必验证必 commit |
| NFR-10 | 回归防线 | 发布前 52 存量测试 + 新增测试全过 |

### 3.2 开发安全铁律 (继承 v2 教训, 强制执行)

| 编号 | 规则 |
|------|------|
| RULE-1 | 每版本只做一件事, 不混合安全/功能/重构 |
| RULE-2 | 禁止批量正则替换 HTML (防破坏 script 块) |
| RULE-3 | 每次前端改动后浏览器验证: 登录 → 策略总览 → 日历 |
| RULE-4 | 操作 data/ 前先 `cp -r data/ data.backup/` |
| RULE-5 | dev 目录 (ops) 不做 git 操作, 全部 git 走 staging |
| RULE-6 | 不修改 .env / data/ 下真实数据文件 |
| RULE-7 | 不改变后端 /api/ 路径和响应格式 (除非版本内明确规划) |
| RULE-8 | 发布前 SPA 完整性检查: template=0, div≈-10, dual=0 |

#### 4.1.4 阶段 4 — 数据可视化

### 4.2 v3.3.0 — 数据可靠层

**一句话**: 数据不丢、不坏、可恢复。

| ID | 需求 | 验收标准 |
|----|------|----------|
| FR-3.3.1 | 易变数据 JSON → SQLite | users/chat_history/watchlist/groups 入库, 原子事务 |
| FR-3.3.2 | 每日自动备份 | data/ → backups/, 保留 30 天, 启动校验 |
| FR-3.3.3 | 一键恢复 (系统设置页) | 备份列表 + 恢复按钮 + 确认弹窗 |
| FR-3.3.4 | 启动 schema 校验 | 损坏自动告警而非静默 |
| FR-3.3.5 | qresult 新 CSV 自动导入 | 检测变化自动入库 + 导入日志 |

**范围外**: 不迁移 market_cache/merrill_cache (可再生缓存)。
**风险**: 中 — 存储层改动需全量回归 (见 TEST-PLAN TC-3.3.x)。
