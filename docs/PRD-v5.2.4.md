- **动机**：本会话完成 5.2.0~5.2.3 后，短线复盘/策略研究/系统配置 三域并存，存在**联动缺失、新旧视觉并存、加载/缓存不统一**三类问题。本版本系统性收敛。

## 0. 定位与设计原则

### 0.1 一句话定位

把「短线复盘（7 子页）+ 策略研究（6 子页）+ 系统配置」从"各自为政的功能页"打磨成一个**数据联动、视觉统一、加载一致**的整体产品。

### 0.2 三条设计原则

1. **联动优先**：跨页/跨子页的数据与日期要"通"——看涨停池能点进个股弹窗，弹窗能跳日历/自选；短线各子页日期同步；验证条件可次日核验。
2. **一套视觉语言**：所有页面收敛到同一基线（stat-icon 摘要 / badge 色系 / 红涨绿跌 / 统一页面头 / 统一空错态），不因页面新旧而异。
3. **一致的性能心智**：客户端 TTL 缓存 + 服务端 store 缓存 + 按需懒加载 + 竞态防护，全站统一，用户"打开就有"。

### 0.3 边界（不做）

| 不做 | 原因 |
|---|---|
| 新增数据源 / 新策略 | 数据源在 5.2.0~5.2.3 已定型 |
| 重构后端架构 / 换框架 | 风险大，收益低 |
| 回测引擎升级 | 属策略研究主线，另行规划 |
| 交易/下单功能 | 产品红线，永不进 |
