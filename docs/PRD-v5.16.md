# PRD-v5.16: 详情内嵌双栏工作区 (列表→详情 无弹窗模式)

> 版本: v5.16 里程碑 (APP_VERSION 建议 5.6.1)
> 状态: 待批准
> 创建: 2026-09-15
> 前置: v5.15 (F7 复盘日历双栏 / F8.2 每日复盘双栏) 已交付, 双栏交互模式已验证

---

## 1. 背景与动机

v5.15 在**复盘日历**与**每日复盘**落地了「左中栏列表 + 右内容区」双栏模式（点选切换、无弹窗、无关闭按钮），用户反馈良好。

用户希望把这一交互模式**推广到其余核心股票列表页**，统一"看列表 → 看个股详情"的动线，减少弹窗打断：

| 页面 | 子页/区块 | 当前交互 |
|---|---|---|
| 量化日历 | 日/周/月/年视图 | `qc-stock-list` 点击行 → `showStockDetail` 弹窗 |
| 量化日历 | 全部 / 新入池 / 当前持仓 / 已出池 | 同上（`statusFilter` 切换的同一列表） |
| 策略总览 | 策略共识度 TOP5 | `qc-stock-list` 点击行 → 弹窗 |
| 策略研究→短线 | 策略共识榜 | `qc-stock-list` 点击行 → 弹窗 |
| 策略总览 | 大盘行情 | 指数卡 → `showIndexDetail` 弹窗（指数详情） |

## 2. 需求范围 (F1-F6)

### F1: 双栏工作区模式（核心）
将上述股票列表页改为「**中栏 = 股票列表，右栏 = 详情工作区**」：
- 默认选中列表**第一条**，右栏直接渲染其详情（无需点击）
- 点击/键盘切换列表项 → 右栏同步切换详情
- **双栏模式下右栏无关闭按钮**（详情常驻，切换即换内容）
- 右栏内容 = 现有个股详情弹窗的全部能力（K线 / AI评估 / AI问股 / 因子 / 表现 / 自选/入池状态 / AI评估操作）

### F2: 原有弹窗模式保留（配置可调）
- 系统配置 →「界面与个性化」新增**「详情展示模式」**开关：
  - `内嵌双栏`（默认，新交互）
  - `弹窗`（原交互，保留）
- 选择持久化（localStorage + 服务端用户配置，双端一致）

### F3: 移动端保留弹窗
- 视口 ≤ 1024px（与现有 `responsive.css` 断点一致）：**强制弹窗模式**
- 双栏在窄屏不可用（列宽不足），配置项在移动端不生效（灰显提示）

### F4: 覆盖页面清单
| # | 页面 | 列表 | 详情 |
|---|---|---|---|
| F4.1 | 量化日历 日/周/月/年 | 股票池（全部/新入池/当前持仓/已出池 共用） | 个股详情 |
| F4.2 | 策略总览 TOP5 | 共识度 TOP5 | 个股详情 |
| F4.3 | 策略共识榜 | 共识度排行 | 个股详情 |
| F4.4 | 大盘行情 | 指数列表（上证/深证/创业板/沪深300） | 指数详情（`showIndexDetail` 内容，**一并改造双栏，C4-A**） |

### F5: 状态与行为约束
- 双栏模式切换列表项时**不复位详情内部状态**（K线周期、AI tab、已评估结果保留，仅内容随股票切换）
- 切换股票时**销毁并重建该股票的 K线实例**（防图表串号，沿用现有 `disposeKline('stockKlineChart')` 机制）
- 列表为空 → 右栏显示空态（与现有 `qc-state-panel` 一致）
- 双栏模式下列表滚动不丢选中高亮（选中项吸顶可见）

### F6: 一致性
- 双栏视觉与 v5.15 复盘日历/每日复盘一致（250px 中栏 + 内容区，`--qc-space-3` 间距，等高拉伸）
- 中栏列表项展示与现有 `qc-stock-list` 一致（排名/名称/价格/共识徽章等）

## 3. 非目标 (Out of Scope)
- ❌ 不改动复盘日历/每日复盘（已交付，保持现状）
- ❌ 不做"详情面板可拖动/可缩放"（复杂度高，后续版本）
- ❌ 不做多选对比（后续版本）
- ❌ 不改造其他未列出的弹窗（AI评估分析弹窗、美林时钟弹窗等保持现状）
- ✅ 大盘行情**指数详情**在范围内（C4-A，用户确认）

## 4. 决策项 (C1-C6)

| # | 决策 | 选项 | 建议 |
|---|---|---|---|
| C1 | 详情内容复用方式 | A. 抽取 StockDetailDialog 内容为独立组件，双栏/弹窗共用 | **A（推荐）** — 单一实现，两模式渲染同一内容 |
| C2 | 默认模式 | A. 内嵌双栏 B. 弹窗 | **A（推荐）** — 用户期望的新交互 |
| C3 | 配置存储 | A. 仅 localStorage B. localStorage + 用户配置 API | **B（推荐）** — 多端一致 |
| C4 | 大盘行情指数详情 | A. 一并改造为双栏 B. 仅个股，指数保持弹窗 | **A（推荐，用户确认）** — 大盘行情指数卡也接入双栏 |
| C5 | 移动端断点 | A. 1024px B. 768px | **A（推荐）** — 与现有 responsive 断点一致 |
| C6 | 版本号 | A. APP_VERSION 5.6.1 B. 5.7.0 | **A（推荐）** — 点版本，v5.15 补丁级增量 |

- [ ] 配置切回"弹窗"后 5 页恢复原交互

## 6. 风险

| 风险 | 等级 | 缓解 |
|---|---|---|
| StockDetailDialog 抽取重构引入回归 | 中 | 抽取后双模式都跑完整冒烟；K线销毁重建单测 |
| 日历页多 statusFilter 共用一列表，选中态联动复杂 | 中 | 选中态绑定股票代码而非行号；filter 切换时若当前股不在新列表则回退第一条 |
| 配置 API 与现有用户配置系统冲突 | 低 | 复用现有 `user_config` 持久化通道 |
| 双栏右栏内容高导致滚动混乱 | 低 | 沿用 F7 等高方案（grid stretch + 内滚） |
