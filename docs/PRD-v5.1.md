## 0. 系列总纲

### 0.1 定位与目标

V5.0 系列（V5.0.0~V5.0.11）完成了稳定性/数据可靠/回测严谨/风控/报表/体验等 12 个点版本，解决了「系统可信」问题。**5.1.x 回答「研究可信」**：

> 从「打开工具看结果」升级为「**一套可复现、抗过拟合、能沉淀结论的策略研究台**」。

五个产品目标在本系列的分工：

| 目标 | 主打版本 | 说明 |
|---|---|---|
| 研究可复现 | 5.1.0 / 5.1.2 | 研究历史持久化、参数/数据/版本快照、报告存档 |
| 因子可信 | 5.1.1 | 截面处理（去极值/中性化/标准化）、IC衰减/换手、多重检验 |
| 回测可信 | 5.1.2 | 成本模型、前视偏差守卫、样本外纪律、walk-forward 报告 |
| 组合可落 | 5.1.3 | 因子合成→组合、风险度量（回撤/VaR/Calmar）、仓位建议 |
| 结论可沉淀 | 5.1.4 / 5.1.5 | 假设→实验→结论闭环、报告导出、市场复盘结构化 |

### 0.3 依赖关系与独立运行原则

- 每个中版本 = 可独立运行、独立 tag 发布、独立部署的完整版本（全量测试绿 + dev/ops 双端可跑 + Docker 可构建）。
- 逻辑依赖：5.1.0（研究历史/面板模型）为 5.1.1/5.1.2 的实验记录供数；5.1.1（因子评价产出）为 5.1.2（回测严谨）供数；5.1.2（可信指标）为 5.1.3（组合/风险）供数；5.1.1~5.1.3 的产出为 5.1.4（报告/对比）供数；5.1.5 复用 5.1.4 的报告导出。
- 发布节奏：每版本 3-4 个点版本（5.1.0 → 5.1.0.1 → …），出口 = 全量测试绿 + 双端冒烟 0 pageerror；tag v5.1.N.M 触发 CI + Docker。
- 版本纪律：APP_VERSION 单一来源（backend/main_new.py），tag ↔ APP_VERSION 由 CI gate 守护；前端 dist 产物入库。

### 0.4 通用需求基线（每版本必须满足）

1. **可运行**：不依赖任何其他 5.1.x 版本独立可运行。
2. **不回归**：既有 2304 测试全绿（新增门禁不得放宽既有门禁）；令牌/术语/版本/锁文件纪律持续守护。
3. **双端一致**：dev/ops 同步；Docker 镜像可构建。
4. **文档同步**：每版本更新 README/DEPLOYMENT/对应 PRD 状态。
5. **安全底线**：新端点 deny-by-default 门禁；新存储字段备份兼容；策略代码生成（AI 生成 PTrade 代码）保持沙箱/校验不直连。

## 1. 5.1.0 研究基座：研究台重构 + 研究历史持久化

### 1.1 背景与目标

当前策略研究页（V3.6~V5.0.2 迭代）已有 8 个子页：研究概览/量化研究/策略编写/自定义策略/市场复盘/回测/回测历史/扫描。功能点分散、结果无历史存档、实验不可复现。5.1.0 把研究台升级为**结构化、可追溯的研究环境**。

### 1.2 需求清单

| 编号 | 需求 | 优先级 | 说明 |
|---|---|---|---|
| FR-5.1.0.1 | 研究台导航重构 | P0 | 研究概览为仪表盘入口，各功能子页统一「实验面板」模式 |
| FR-5.1.0.2 | 研究历史持久化 | P0 | 因子IC/分层/扫描/回测/稳定性每次运行结果存入研究库（JSON），按「实验」聚合 |
| FR-5.1.0.3 | 实验快照 | P1 | 每次实验记录：策略ID+参数+数据区间+版本(APP_VERSION)+结果摘要，可复现 |
| FR-5.1.0.4 | 实验列表/对比视图 | P1 | 按时间倒序看历史实验，可对比两次实验关键指标 |
| FR-5.1.0.5 | 研究面板数据模型 | P0 | 定义 research_experiment / research_metric 数据结构，兼容现有 factor_ic/walkforward 输出 |
| FR-5.1.0.6 | 结果导出 CSV | P2 | 研究结果可导出（复用回测 CSV 拼装） |

### 1.3 验收标准

- 一次因子IC运行后，实验记录可在研究历史中查到，含参数与结果摘要。
- 同一策略两次不同参数扫描，可在对比视图并列展示关键指标。
- 全量测试绿；研究历史无数据时显示空态。

## 2. 5.1.1 因子研究深化：截面处理 + 衰减/换手 + 合成

### 2.1 背景与目标

现有 factor_ic.py 支持 Spearman/Pearson IC、n5/n10/n20 窗口、分层回测。缺：截面预处理（去极值/中性化/标准化）、IC 衰减/换手分析、多因子合成、多重检验校正。

### 2.2 需求清单

| 编号 | 需求 | 优先级 | 说明 |
|---|---|---|---|
| FR-5.1.1.1 | 截面处理三步 | P0 | 去极值（MAD/winsorize）→ 中性化（行业+市值回归取残差）→ 标准化（z-score）；顺序固定、参数可选 |
| FR-5.1.1.2 | IC 衰减分析 | P0 | 因子 IC 随持有期（1/5/10/20日）变化曲线，推荐最优持有期 |
| FR-5.1.1.3 | 换手率分析 | P1 | 各分层/组合年化换手，与成本敏感性联动 |
| FR-5.1.1.4 | 多因子合成 | P1 | 等权/IC加权/ICIR加权合成，合成后重跑完整评价 |
| FR-5.1.1.5 | 多重检验提示 | P2 | 试验因子数记录 + IC 显著性校正提示（避免纯数据挖掘） |
| FR-5.1.1.6 | 因子详情面板 | P1 | 因子定义/参数/覆盖度/近1-2年表现专测 |

### 2.3 验收标准

- 截面处理三步参数可选且输出中性化后因子。
- IC 衰减图展示 1/5/10/20 日 IC 均值变化。
- 两个因子等权合成后可重跑 IC/分层评价。
- 覆盖 2015 股灾/2018 熊市/2020 疫情/2022 熊市的因子表现专测。

## 3. 5.1.2 回测严谨性：成本/前视/样本外/walk-forward

### 3.1 背景与目标

现有回测（backtest-core.js + backend/backtest.py + walkforward.py）已有基础指标。缺：A股完整成本模型（印花税/滑点/佣金）、前视偏差守卫、严格的样本外纪律、walk-forward 滚动验证报告。

### 3.2 需求清单

| 编号 | 需求 | 优先级 | 说明 |
|---|---|---|---|
| FR-5.1.2.1 | 成本模型升级 | P0 | 单边成本=A股佣金(0.03%可配)+滑点(可配)+印花税(卖出0.05%)；保守默认单边 0.1%~0.15%，可「成本翻3倍压力测试」 |
| FR-5.1.2.2 | 前视偏差守卫 | P0 | 信号 t 日收盘算、t+1 成交；审计工具检测用当日 close 成交的违规；报告标注成交假设 |
| FR-5.1.2.3 | 样本外纪律 | P0 | 一键切 70% 训练 / 30% 样本外；参数只能在训练段定，OOS 段一次性展示并标注「未触碰」 |
| FR-5.1.2.4 | Walk-forward 报告 | P0 | 滚动窗口重估参数前推，输出每段 OOS 表现 + 稳定性诊断（复用 walkforward.stability_report） |
| FR-5.1.2.5 | 回测可信度清单 | P1 | 交易次数<20/样本期短/无基准/成本过低时给出警示 |
| FR-5.1.2.6 | 基准与分年度 | P1 | 沪深300/中证500 基准对比 + 各年分年度收益表 |

### 3.3 验收标准

- 成本参数可配，默认保守口径；「成本×3 压力测试」一键跑出。
- 审计能检出「同日收盘成交」式前视违规并标注。
- OOS 段展示「未触碰」标注；walk-forward 报告含各段 OOS 指标与 CV 稳定性。
- 分年度收益 + 基准对比表。

## 4. 5.1.3 组合与风险：因子→组合 + 风险度量 + 仓位

### 4.1 背景与目标

从「选股因子」到「可落组合」：合成因子→选股（top N）→组合回测→风险度量（最大回撤/VaR/Calmar/换手）→仓位建议（Kelly/风险平价参考）。

### 4.2 需求清单

| 编号 | 需求 | 优先级 | 说明 |
|---|---|---|---|
| FR-5.1.3.1 | 组合构建 | P0 | 合成因子→选 top N（可配 N/权重：等权/市值加权）→组合净值 |
| FR-5.1.3.2 | 风险度量 | P0 | 最大回撤/年化波动/Sharpe/Sortino/Calmar/VaR(95%)；净值反推指标防复利误差 |
| FR-5.1.3.3 | 风险报告 | P1 | 回撤区间标注 + 风险指标表 + 尾部风险（极端段专测） |
| FR-5.1.3.4 | 仓位建议 | P2 | 参考仓位（Kelly 分数 / 风险平价权重），标注为「参考非投资建议」 |
| FR-5.1.3.5 | 容量/流动性提示 | P2 | 小票按成交量 1% 参与度限仓提示 |

### 4.3 验收标准

- top N 组合净值可生成，含基准对比。
- 风险指标表（回撤/波动/Sharpe/Sortino/Calmar/VaR）齐全。
- 仓位建议标注「参考非投资建议」。

### 5.1 背景与目标

把「假设→实验→结论」沉淀为可追溯记录，支持导出投研报告。

### 5.2 需求清单

| 编号 | 需求 | 优先级 | 说明 |
|---|---|---|---|
| FR-5.1.4.1 | 实验记录扩展 | P0 | 5.1.0 实验记录增加：假设/结论/标签/备注字段 |
| FR-5.1.4.2 | 研究报告导出 | P1 | 单次实验 → Markdown/PDF 研究报告（含指标表/净值图/结论） |

## 6. 5.1.5 市场复盘结构化 + 知识沉淀

### 6.1 背景与目标

现有市场复盘（V3.17.2）为列表+详情。升级为**结构化复盘**（板块/风格/因子维度），沉淀为可检索知识。

### 6.2 需求清单

| 编号 | 需求 | 优先级 | 说明 |
|---|---|---|---|
| FR-5.1.5.1 | 复盘结构化 | P0 | 复盘按「日期/板块/风格/因子/要点/策略启示」结构化字段 |
| FR-5.1.5.2 | 复盘→策略关联 | P1 | 复盘可关联到策略实验，策略页反查相关复盘 |
| FR-5.1.5.3 | 复盘检索 | P2 | 按日期/板块/标签检索历史复盘 |

### 6.3 验收标准

- 复盘新增结构化字段可编辑/展示。
- 一条复盘可关联一个策略实验；策略详情可反查。

## 7. 非目标（本系列明确不做）

- **实盘下单**：研究台产出结论与参考仓位，不接真实交易（实盘属于 V5.2+ / live-trading 域）。
- **机器学习选股**：LightGBM/XGBoost 合成暂不做（数据量/工程代价大），保持因子逻辑可解释。
- **历史行情扩充**：不引入新数据源/历史深数据（依赖现有三源热备），避免范围蔓延。
- **研究台移动端**：研究页保持桌面优先，移动端只保证不破版。
