# PRD v5.12.0 — 界面体验与工程收敛（UX-6）

- 版本：v5.12.0（APP_VERSION，基线 v5.11.1）
- 输入：`docs/EVAL-UI-GLOBAL-v6.9.7.md`（全局界面评估报告 P0/P1 已完成，§10.3 遗留项）
- 目标：把评估报告里"可测量项已归零"之后剩下的**体验取舍项**与**工程债**收敛为一版可交付迭代

## 1. 背景与问题

| 编号 | 现状（实测） | 影响 |
|---|---|---|
| P-1 | 564 个交互元素中 **56.4% < 32px**（EP size="small" 默认 24px 高）；且 `info_density` 偏好（3 档、后端持久化、有单测）**定义了却从未生效** —— `applyDensity()` 无任何调用点，`data-density` 属性从未写入 DOM | 触控/平板可达性不达标；三档密度是"死功能"，用户改了没反应 |
| P-2 | 登录页为**整屏品牌渐变 + 居中窄卡**（卡片 ~420px），"登录/访客登录"两个按钮同为 `type="primary"` 等权 | 首屏第一印象与产品成熟度不匹配；主次操作不分 |
| P-3 | 今日一屏 4 张 KPI 卡各带 3px 彩色左边框 + 同色图标底（蓝/绿/琥珀/橙），颜色不承载任何语义；结构性表面（侧栏/头部）使用 `backdrop-filter` 毛玻璃 6 处 | 装饰性用色稀释语义色信号；毛玻璃在数据密集界面降低文字锐度 |
| P-4 | `watchlist.js` 评分趋势图自建 option，未走 `getEChartsTheme()`；暗色下部分图表轴线/网格仍用亮色兜底值 | 明暗切换时图表层次不统一 |
| P-5 | 死 token 51 个；断点 5 个杂散值（767/480/1024/1100/1279）；`!important` 228 处 | 规则只增不减，后续改动风险高 |

## 2. 目标与非目标

**目标**
1. 密度三档全部生效，并把可交互元素最小命中区纳入密度体系（桌面 ≥32px / 触控 ≥44px）。
2. 登录页改为"品牌区 + 表单区"双栏结构，单一主 CTA，主次分明，窄屏优雅降级。
3. 装饰性用色收敛：KPI 卡不再用无意义彩色边框；结构性表面的毛玻璃改为实底。
4. 图表主题统一：全部 ECharts 实例走同一主题对象，暗色轴线/网格达非文本对比度 ≥3:1。
5. 工程债首批清理：删除全部死 token、断点归一到 4 档、`!important` 下降 ≥30%。

**非目标**
- 不改变任何后端 API 契约与数据口径；不新增依赖；不重做暗色主题的完整视觉语言（仅图表与令牌贯通）。

## 3. 需求（FR）

### FR-5.12.1 密度模式生效与命中区保障（P0）
- **FR-5.12.1.1** 启动时按 `info_density` 偏好写入 `data-density`（默认 `comfortable`），偏好变更即时生效并持久化。
- **FR-5.12.1.2** 头部"外观"面板新增**信息密度**三档切换（紧凑/标准/宽松），与主题模式/色相并列。
- **FR-5.12.1.3** 三档驱动可交互元素尺寸：
  - 紧凑：EP 组件 small=24px、default=28px；图标按钮 28px；行高压缩
  - 标准：EP small=28px、default=32px；图标按钮 32px
  - 宽松：EP small=32px、default=36px；图标按钮 36px；行高放宽
- **FR-5.12.1.4** 命中区兜底：指针设备下 `button/a[role=button]/input/select` 最小高度 32px；`@media (pointer: coarse)` 下 44px（不改变视觉尺寸，用 padding/伪元素扩展命中区）。

### FR-5.12.2 登录页重塑（P1）
- **FR-5.12.2.1** 布局改为双栏：左侧品牌区（品牌名/一句话定位/品牌渐变细条，≤520px），右侧表单区（中性表面）。
- **FR-5.12.2.2** 主 CTA 唯一：`登录` 为 primary；`访客登录` 降级为 default（次要）。
- **FR-5.12.2.3** 窄屏（≤900px）品牌区折叠为顶部品牌条，表单区占满宽度。
- **FR-5.12.2.4** 保留既有 i18n key（login.title/subtitle/desc/username/password/submit/guest/footer），不新增文案依赖；表单可键盘操作与回车提交。

### FR-5.12.3 视觉降噪（P1）
- **FR-5.12.3.1** KPI 卡（`.stat-card`）移除无语义彩色左边框；图标底统一为品牌/中性浅底，仅"状态类"（涨/跌/警告/错误）保留语义色。
- **FR-5.12.3.2** 结构性表面（`.sidebar`、`.qc-header`）去除 `backdrop-filter`，改实底 + 1px 边；浮层（对话框/下拉/面板）保留毛玻璃。

### FR-5.12.4 图表令牌贯通（P1）
- **FR-5.12.4.1** 所有 ECharts 实例的基础 option 统一来自 `getEChartsTheme()`（`watchlist` 评分趋势图接入）。
- **FR-5.12.4.2** 暗色下轴线对比度 ≥3:1、网格线 ≥1.5:1（沿用既有令牌门禁口径）。
- **FR-5.12.4.3** 主题切换时全部已挂载图表重绘（`refreshAllCharts` 覆盖率 100%）。

### FR-5.12.5 工程债首批清理（P2）
- **FR-5.12.5.1** 删除全部死 token（以脚本判定：CSS/tokens.css 定义且 CSS 与 JS 均无引用）。
- **FR-5.12.5.2** 断点归一为 480 / 768 / 1024 / 1280 四档（767→768、1100→1024、1279→1280）。
- **FR-5.12.5.3** `!important` 数量在 themes.css 内下降 ≥30%（仅合并/去重冗余覆盖，不改语义）。

## 5. 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 尺寸变量全局生效导致版面溢出 | 布局错位 | 三档分别截图复核关键页；保留 compact 为"与今天一致"的兜底 |
| 登录页结构改动破坏登录流程 | 无法登录 | 保留 v-if/表单绑定不变，仅改结构层；e2e 冒烟 + 手工登录验证 |
| 死 token 删除误删运行期引用 | 样式丢失 | 判定脚本同时扫描 `var(--x)` 与 `getCSSVar('--x')`；删除后跑全量测试 + 视觉复核 |
| `!important` 合并引入回归 | 覆盖失效 | 仅删"同选择器同属性"的重复声明；对比度审计复测 |
