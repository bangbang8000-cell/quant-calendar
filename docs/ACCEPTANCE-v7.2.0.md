## 守恒断言的实际结果

概念拓扑做了**硬约束**：`Σ概念净额 == Σ股票净额`（容差 1e-6）。三个交易日实测 **diff = 0.0（精确相等）**，184 个概念、每日 100–116 个。无概念的股票进 `__unmapped__` 桶参与守恒，不做静默丢弃。
