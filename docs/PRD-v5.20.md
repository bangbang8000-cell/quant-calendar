## 1. 背景与动机

v5.19 把「中栏列表 + 右栏详情工作区」推广到 我的自选 / 美林时钟 / 重点跟踪, 并验证了通用壳 `qc-detail-split`。剩余两处**同构页面**仍以「行内展开」承载详情:

| # | 问题 | 走查证据 |
|---|---|---|
| P0-1 | **详情挤占列表**: 评估历史 / 问股历史 均为「按 日期/月/个股 分组 → 点分组头展开 → 组内虚拟列表」; 详情以**行内展开**呈现, 展开后列表被压缩, 无法边看列表边看详情 | `ai-page.js` L310-416 (`history`) / L417-548 (`chat_history`) |
| P0-2 | **两页与其余页交互不一致**: 自选/美林/重点跟踪 已是「点行 → 右栏详情」, 而这两页仍是「点行 → 行内展开」 | `history-record.js` L98-101 `view()` |
| P1-3 | **模板 6 处重复**: 两页 × 三种视图 (日期/月/个股) 共 6 处渲染 `qc-history-record` 的虚拟列表, 双栏改造需逐处收敛 | v3.16 已把行模板收敛到组件, 列表包装仍在 6 处重复 |

**关键可行性发现 (勘察结论)**: 两页的详情入口 `viewAiResult(item)` (watchlist.js L1042) 与 `viewChatSession(session)` (ai-chat.js L163) **本就复用同一个 `qc-stock-detail-dialog`** —— 前者设 `stockDetailTab = ai`, 后者设 `= chat`。而 `index.html:160` 的全局弹窗带 `v-if="!detailSplitEnabled"`, 双栏时不渲染。**故 F7 无需新建任何详情组件**: 在右栏放一个 `:embedded="true"` 实例即可, 且 tab 切换由既有函数自动完成。

本版本目标: **不动数据管道与 AI 逻辑**, 把这两页接入既有双栏模式, 消除交互不一致。

## 2. 需求范围 (F1-F5)

### F1: 两页双栏化 (P0)
- `ai-page.js` 的 `history` 与 `chat_history` 两个子页: 在内容卡片的列表区包入 `qc-detail-split`
  - `#list`: 三视图切换按钮 + 分组卡片 (分组头含 复选框/日期/条数/展开箭头) + 组内 `qc-virtual-list` + `qc-history-record` 行
  - `#pane`: `qc-stock-detail-dialog :embedded="true"`
- 批量操作工具栏 (含 6 个按钮) 保留在**双栏之上全宽** (与 v5.19 F4 自选页同理, 避免 35% 中栏挤压)
- 行点击沿用既有 `view()` (即 `viewAiResult` / `viewChatSession`), **双栏/弹窗两模式共用** — 无需分流

### F2: 双栏自动载入首条 (P1)
- 进入双栏且右栏为空时, 自动载入当前视图下的**第一条记录**入右栏
- 镜像 v5.16/v5.19 既有做法 (`strategies-page.js` 的默认选中 watch + v5.19 美林 `merrill` 分支)
- 需注意: 两页有 3 种视图 (日期/月/个股), 自动载入应作用于**当前视图的首组首条**

### F3: 窄栏行适配 (P0)
- `qc-history-record` 行结构: `[复选框][内容: 头部(代码 名称 星标 标记) + 评分徽章 / 底部(时间 来源 维度)][删除按钮]`
- 中栏 35% (约 413px) 下需适配; 组内虚拟列表 `:row-height="72"` 为**固定行高**, 故适配须落在 72px 内 (或按双栏态提高行高, 与 v5.19 F4 自选页同法)
- 约束: **信息项不减** (代码/名称/评分/评级/时间/来源/维度/删除入口 全部保留)

### F4: 多选与批量操作保留 (P0)
- 记录级复选框、分组头全选、批量重评 / 加入自选 / 批量删除 / 取消选择 全部保留
- 复选框点击必须 `@click.stop`, 不触发行点击

### F5: 弹窗模式回退 (P0)
- `detailDisplayMode = dialog` 或视口 ≤1024px 时: 列表全宽, 点行弹窗 (既有行为)
- 与 v5.19 一致: 分隔条与右栏不渲染, 列表 `w-100`

## 3. 非目标 (Out of Scope)

- ❌ 不改动 评估/问股 的数据结构、接口与 AI 逻辑; 不改动分组视图与虚拟滚动机制
