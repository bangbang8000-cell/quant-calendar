## 1. 背景

v6.5.8 已是一版功能完整、架构健康的版本（前端零构建 SPA + FastAPI + 三源热备），但本轮评估实测出**两类系统性问题**：

1. **「取不到数就写 0」的静默降级**：美林时钟的宏观指标在 AKShare 列名变更后恒返回 0，0 又把 z-score 打穿，导致维度评分、阶段判定、历史轨迹连锁失真——用户看到的「衰退期 + 置信度高」是假的。
2. **「连接/渲染生命周期」缺乏兜底**：自选实时报价只在页面加载时连一次 WS，SPA 登录后永不重连；自选列表在特定现场条件下整块不渲染且无任何提示。

以及一批**明确的数据错误**（指数成交额错 10 倍）与**信息缺失**（市值、多周期涨跌幅、K 线悬浮框字段）。

本轮的目标不是加功能，而是**把「用户看到的数字」和「界面是否真的渲染」这两件事变成可相信的**。

## 2. 目标与非目标

### 2.1 目标（可度量）

| ID | 目标 | 度量口径 |
|---|---|---|
| G1 | 自选列表**永远能渲染出与计数一致的行数** | `watchlist.length === 可见行数`，13 只必出 13 行 |

- ❌ 不改美林时钟的指标体系与四象限理论模型（只修取数与防抖）

## 4. 需求清单

> 优先级：**P0** = 不可用/数据错误，必须修；**P1** = 明确需求或显示错误；**P2** = 技术债与护栏。
> 每条需求给出：现状 → 期望 → 可验证断言。

### FR-6.6.1 自选列表渲染保障（P0，对应 P0-1b）

**现状**：标题「共 13 只」与工具栏正常，列表区域零 DOM、无红色报错、硬刷新无效；同双栏组件的「评估历史」页正常。

**期望**
1. 自选列表在**常规规模（≤50 只）下不使用虚拟滚动**，直接渲染真实 DOM 行——13 只就是 13 个 `.watchlist-item` 节点，可用 `querySelectorAll` 计数、可 `Ctrl+F` 搜索、可整页滚动。
2. 超过 50 只时才启用现有虚拟列表（保留性能能力，不丢）。
3. **渲染自检**：若 `sortedWatchlist.length > 0` 但实际渲染行数为 0，必须显示**可诊断降级面板**（含原因摘要与「导出诊断信息」按钮），**不允许静默空白**。
4. **启动自检**：`window.__quantComponents` 必需组件缺失，或前端版本与 `/api/health` 版本不一致时，顶部显示可关闭横幅。
5. **诊断入口**：提供「诊断此页」动作，一键导出 DOM 结构 + 关键状态 + 版本号 JSON（与本次现场探针同构）。
6. 保留现有 `qc-virtual-list` 组件与其它页用法不变（仅自选页切换策略）。

**可验证断言**
- AC-14：13 只自选 → `.watchlist-item` 数 = 13 = 标题计数。
- AC-15：注入「有计数无行」状态 → 出现降级面板，含导出按钮。
- AC-16：删掉一个必需组件注册 → 顶部横幅出现。
- 回归：>50 只时仍走虚拟列表且滚动流畅。

### FR-6.6.2 自选实时报价连接生命周期（P0，对应 P0-1a）

**现状**：只有页面加载时尝试连接一次；SPA 登录后 `realtimeWsState` 停在 `idle`，界面永远显示「连接中...」。

**期望**
1. **登录成功即连接**：`handleLogin()` 与 `handleGuestLogin()` 成功后立即建立 WS（无需刷新）。
2. **登出即断开**：调用 `disconnectRealtimeQuotes()`，报价清空，状态回初始。
3. **状态可解释**：`idle`/`connecting`/`open`/`closed` 四种状态对应四种明确文案，不再把 `idle` 显示成「连接中...」。
4. **看门狗**：`connecting` 超过 8s 必须转为「已断开（点击重连）」，不出现无限转圈。
5. **退避重连**：断线后指数退避（1s→2s→4s→…，上限 30s），页面 `visibilitychange` 回前台时立即重试一次。
6. **登录态监听**：token 出现/消失时自动连接/断开（覆盖非表单登录路径）。

**可验证断言**
- AC-1：SPA 登录 → ≤2s 内建立 WS，13 只全部出现报价行（价格/涨跌幅）。
- AC-2：登出 → WS 关闭、报价清空；再登录 → 重新建立。
- AC-3：拦截 WS → 8s 内文案变「已断开」，无无限「连接中」。

### FR-6.6.3 美林宏观取数可靠性与缺失语义（P0，对应 P0-2）

**现状**：17 项指标中 GDP/CPI/PPI/社融 恒为 0 且覆盖合理默认值；接口仍标 `_data_source: "AKShare实时数据"`。

**期望**
1. **列名兼容链**：每个指标的取数列按优先级尝试（如 CPI：`今值` → `现值` → `value` → `同比`），任一命中即用。
2. **排序与脏值**：DataFrame 统一按日期**升序**后取最新；`NaN`/空串/非数值一律跳过，不得转 0。
3. **缺失语义**：取不到的指标**不写入 0**，保留「未知」，并在响应中列入 `missing[]`，`quality` 取 `full`/`partial`。
4. **不覆盖原则**：`indicators.update(real_data)` 只允许覆盖**真实取到**的键；未取到的键保持「未知」而非回落成硬编码估计值参与打分（估计值可展示，但必须标 `estimated: true` 且**不参与 z-score**）。
5. **溯源真实**：`_data_source` 必须反映真实来源（如 `AKShare(macro_china_cpi)` + 逐项来源表），不得笼统写「实时数据」。
6. **第二源兜底**：AKShare 失败时尝试 tushare 宏观接口（若可用）；双源皆失败 → 全部进 `missing[]` + `quality=insufficient`，**明确降级**而不是给假数字。

**可验证断言**
- AC-4：真实列名 fixture → `quality=full`；缺列/NaN/乱序 fixture → 对应项进 `missing[]` 且**值不为 0**。
- 新增单测覆盖：倒序帧取最新、含 `-` 的中文列名、社融无存量同比、全空帧。

### FR-6.6.4 美林阶段判定防抖、历史订正与人工锁定（P0，对应 P0-3 / D4 / D5 / D8）

**现状**：历史含 0 天/1 天/6 天阶段跳变；`current_stage` 与时间轴互不一致；快照 100 条。

**期望**
1. **防抖规则**
   - 阶段切换需**连续 2 次评估**落在新象限才确认（滞回）；
   - 自动阶段**最短持续 20 个交易日**，未满不切换；
   - 单次评估的最大单步变动受指标缺失约束：某维度缺失时该维度**不参与打分**（而非按 0 计分）。
2. **历史不重复**：同一象限的连续评估**不得**重复写入转换记录（现有去重只按象限相等判断，需补「同一交易日内多次评估只算一次」）。
3. **历史订正（D4）**：对 2026 年所有 `trigger == 'boundary'` 且 `duration_days <= 3` 的记录，标记 `archived: true` + `legacy: true` + `recomputed_from`，**保留原记录不删除**；重算生成新快照并标 `recomputed_at`。
4. **人工锁定（D5）**：admin 可将当前阶段「锁定」；锁定时自动算法不得改写阶段，界面显示「人工锁定」徽标；解锁后恢复自动。锁定/解锁写审计日志。
5. **订正可见（D8）**：美林页面显示「数据订正于 YYYY-MM-DD」角标，点击可看订正说明（改了哪些记录、当前阶段变化）。
6. **三处一致**：`current_stage`（接口）、「当前阶段」徽标、「本轮演进」时间轴必须一致，由同一数据源派生。

**可验证断言**
- AC-5：连打 10 次同象限评估 → 历史不新增记录；阶段最短持续 ≥20 交易日。
- AC-6：订正后数据中不存在 `duration_days <= 3` 的自动阶段（人工记录豁免）。
- AC-7：接口阶段 == 徽标 == 时间轴末节点。
- AC-20：角标存在；锁定入口仅 admin 可见；锁定后接口阶段不随算法变化。

### FR-6.6.5 成交额单位修正（P0，对应 P0-4）

**现状**：指数与个股成交额用 `/10000` 折算「亿」，实际单位是千元，结果放大 10 倍。

**期望**
1. 统一在**后端**把成交额归一为「元」（`amount_yuan`），前端只做 `÷1e8` 显示「亿」。
2. 指数与个股走同一套换算，杜绝各写一份。
3. 前端保留旧字段兼容一个版本（读不到新字段时回退旧逻辑，但不再 `÷10000`）。

**可验证断言**
- AC-8：上证成交额显示 ≈7,156 亿（±1%）；个股成交额与 `vol(手) × price × 100` 互校一致。

### FR-6.6.6 总市值与多周期涨跌幅（P0，对应 P0-5 / D2 / D3）

**现状**：蜡烛图界面只有最新点位/涨跌额/成交量/成交额；个股详情只有成交量。

**期望**

**新增后端接口** `GET /api/market/quote-summary/{code}`（个股与指数通用），字段契约见 §5.1。

界面（指数详情 + 个股详情 + K 线区域）展示：

| 字段 | 个股 | 指数 |
|---|---|---|
| 最新价 / 涨跌额 / 涨跌幅（当日） | ✅ | ✅ |
| 周 / 月 / 季 / 年 涨跌幅 | ✅ | ✅ |
| 总市值（亿元） | ✅ | **「指数不适用」**（D2） |
| 成交额（亿元） | ✅ | ✅ |
| 换手率 | ✅ | 若可得则显示，否则隐藏 |

**口径（D3）**：`pct_week/month/quarter/year` 基准 = **上一自然周期最后一个交易日的收盘价**。
- 停牌/无当日数据：用最近可得交易日价，并标 `as_of`。
- 上市不足一个周期（如新股无「上年末收盘」）：该周期返回 `null` 并进 `missing[]`，界面隐藏该项（不显示 `--`）。
- 小数位：统一 2 位。
- 指数市值：`total_mv_yuan` 返回 `null` + `missing:["total_mv_yuan"]`，界面按 D2 文案渲染。

**可验证断言**
- AC-9：指数与个股详情均出现 5 个周期涨跌幅字段；个股出现总市值；指数显示「指数不适用」。
- AC-19：指数不显示市值数字（断言无「亿」数值节点）。

### FR-6.6.7 K 线悬浮框信息补全（P0/P1，对应 P0-6）

**现状**：`charts.js:149-180` 只输出 日期/开/收/低/高/成交量/MA/VOL_MA5。

**期望**：悬浮框补齐并在无数据时不显示该行（而非 `--`）：

| 行 | 格式 | 说明 |
|---|---|---|
| 日期 | YYYY-MM-DD | 保留 |
| 开 / 高 / 低 / 收 | 2 位小数 | 保留 |
| **涨跌幅** | ±x.xx%，红涨绿跌 | 新增（相对前一根收盘） |
| 成交量 | x.xx 万手 | 保留 |
| **成交额** | x.xx 亿元 | 新增 |
| **换手率** | x.xx% | 新增（个股，指数无则隐藏） |
| **总市值** | x.xx 亿元 | 新增（个股；指数隐藏） |
| MA5/MA10/MA20、VOL_MA5 | 2 位小数 | 保留 |

**可验证断言**
- AC-10：tooltip formatter 单测覆盖上述字段；浏览器 hover 断言文本含「涨跌幅」「成交额」「换手率」；无数据项不出现 `--`。

### FR-6.6.8 一级菜单「策略」→「策略概览」（P1，对应 P1-1 / D1）

## 5. 数据契约（开发必须严格遵守）

### 5.1 `GET /api/market/quote-summary/{code}`

```jsonc
{
  "success": true,
  "data": {
    "code": "600519.SH",
    "name": "贵州茅台",
    "is_index": false,
    "as_of": "2026-10-29",              // 数据所属交易日
    "fetched_at": "2026-10-30T15:02:11+08:00",
    "price": 1452.30,                    // 元, 2 位
    "prev_close": 1468.00,
    "change": -15.70,
    "pct_day": -1.07,                    // %
    "pct_week": 2.31,                    // %
    "pct_month": -4.12,                  // %
    "pct_quarter": 8.90,                 // %
    "pct_year": 12.34,                   // %
    "vol_shares": 443564144,             // 股
    "amount_yuan": 7156206949.06,        // 元（已由千元归一）
    "total_mv_yuan": 31670163029.00,     // 元（由万元归一）；指数为 null
    "circ_mv_yuan": 31670163029.00,      // 同上
    "turnover_rate": 5.5356,             // %
    "quality": "full",                   // full | partial | insufficient
    "missing": [],                       // 缺失字段名数组
    "sources": {
      "quote": "tushare",
      "daily_basic": "tushare",
      "kline": "sse"
    }
  }
}
```

**硬约束**
- 所有金额单位为**元**，所有比率为**百分数**（`-1.07` 表示 -1.07%）。
- 缺失一律 `null` + 进 `missing[]`，**禁止用 0 占位**。
- 指数 `total_mv_yuan` / `circ_mv_yuan` 恒为 `null` 且进 `missing[]`（后端不猜）。
- 任何字段取不到时不得返回 `0`，也不得编造。
- 该接口需登录（与 `/api/market/kline/*` 同级权限）。

### 5.2 美林时钟响应增补（`GET /api/market/merrill-clock`）

```jsonc
{
  "indicators": { "pmi": 50.8, "cpi": null, "...": "..." },
  "missing": ["cpi", "ppi", "gdp_growth", "social_financing"],
  "quality": "partial",                  // full | partial | insufficient
  "estimated": ["usd_cny"],              // 仅估算、且不参与 z-score 的项
  "sources": { "pmi": "akshare:macro_china_pmi", "m2_growth": "akshare:macro_china_m2" },
  "stage": {
    "current": "recovery",
    "since": "2026-08-11",
    "days": 55,
    "locked": false,                     // D5 人工锁定
    "locked_by": null,
    "locked_at": null
  },
  "correction": {
    "recomputed_at": "2026-10-30",
    "archived_count": 6,
    "note": "归档 2026 年 boundary 抖动 6 条，不删除原始记录"
  }
}
```

### 5.3 历史与快照订正字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `archived` | bool | 已归档（不参与当前展示统计） |
| `legacy` | bool | 旧算法产物 |
| `recomputed_from` | string\|null | 从哪条记录重算而来 |
| `recomputed_at` | string\|null | 重算时间 |
| `locked` | bool | 人工锁定阶段产生的记录 |

**不变式**：任何订正都**不得物理删除**既有记录；`data/merrill_history.json` 与快照文件必须先备份再改。
