## 0. 定位与设计原则

### 0.1 一句话定位

新增**一级菜单「短线复盘」**——把 A 股短线每天要做的复盘工作（涨停池 / 连板梯队 / 龙虎榜 / 板块资金 / 题材归因 / 昨日涨停股反馈）自动化：**拉数据 → 派生情绪指标 → 五个分析师各读一面 → 收敛成一份可读的盘面研判**。

### 0.2 三条设计原则（借鉴 vibe-astock 的核心哲学）

1. **复盘是事实工作，不是推荐**。界面九成是**硬指标层**——赚钱效应 / 晋级率 / 连板溢价 / 梯队结构 / 情绪周期 / 封板质量 / 亏钱效应——**全部纯计算、数据源直出、不经过 AI**。AI 的角色是把多个数据源串成一个能读的故事，不是选股。**全产品不推荐个股、不给参与倾向、不给买卖点位**（个股一律只作客观陈述）。

2. **数据诚实性优先（"不骗人"护栏）**。宁可说"取不到"，也不拿有偏差的样本冒充全体、拿盘中值冒充收盘、拿历史均值冒充缺失值、拿行业分类冒充题材。具体护栏见 §5。

3. **与现有产品互补、复用最大化**。短线复盘补的是"日线级短线情绪视野"，与美林时钟（宏观周期）互补；最大化复用现有三源数据层、AI 多模型、scan_engine 涨停判定、market_review 复盘框架、scheduler、SQLite 迁移框架、报表推送。

### 0.3 边界（本主线明确不做）

| 不做 | 原因 |
|---|---|
| 个人交易日志 / 在险资金 / 风险宪法 / 模式卡（vibe-astock journal 部分） | 我们是市场复盘工具，不是记账本/交易体检；用户交易侧是另一话题 |
| 个股深挖多 agent（四分析师+辩论） | 已有「AI 智能评估」+「智能问股」覆盖个股分析 |
| 盯盘实时异动流 / 资讯雷达 | 已有异动扫描 + 实时行情基础，不在本主线 |
| 任何选股建议 / 买卖时机 | 产品红线，§5 用测试锁住 |

## 5. 数据诚实性纪律（贯穿全部版本，用测试锁住）

借鉴 vibe-astock，以下纪律**逐条落为守卫测试**：

1. **空数据 ≠ 0**：取数失败返回 None/`available:false`，绝不返回 0 家；判据必须 `is not None`（"今天跌停 0 家"是合法空结果）
2. **失败统一信封**：取数失败统一 `[⚠️ ...]` 前缀，降级判定只认此前缀
3. **覆盖率闸门**：批量行情类指标 <50% 不可用、<90% 标 partial（prompt/UI 必须提示样本不全）
4. **定稿优先**：昨日涨停股表现优先走定稿记录，实时行情仅在"目标日=最近已收盘场次"时兜底
5. **实时不冒充**：盘中快照过点不补，历史日绝不现抓；涨停池钉住已收盘场次（不显示盘中半成品）
6. **涨跌幅制度感知**：涨停/跌停按每只票制度判定（10cm/20cm/北交所/ST）
7. **unavailable 标注**：几乎每个输出带 `available` + `reason`；验证条件数据不足 = `None`（不算判错）
8. **口径如实披露**：情绪周期是"十日相对读数"；梯队断层是"跨题材"；板块资金历史场次标注"实时值口径"
9. **原始归档**：归档存数据源原样行（raw 标志位），归一化行检不出字段漂移就如实说明
10. **制度变化人工登记**：绝不从数据反推制度变化
