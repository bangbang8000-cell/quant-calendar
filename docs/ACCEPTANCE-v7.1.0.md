## 口径守护首次"抓到自己"

`industry_strength.meta.caliber` 原本写「…不是「指数贡献」」，被 **B5.2 的禁称守护拦下**，真实数据导出直接失败：

```
ValueError: 导出物不合格: 违规=['指数贡献'] 缺项=[]
```

改为「不得称指数权重贡献」后导出通过。**这说明守护是真的在跑，不是摆设**——连"引用禁称来解释禁称"都不允许。
