# 参考历史持仓 (无 key 预览样例)

本目录为 v3.21 随仓库发布的**精简历史持仓样例**，用于：

1. **无 key 部署方预览程序功能**（策略列表 / 持仓查看），无需配置 tushare token
2. 展示持仓文件格式（与外部量化程序 qresult 完全一致的矩阵：行=交易日，列=股票代码，值=1 持有）

## 样例说明

| 文件 | 策略 | 说明 |
|---|---|---|
| 多因子策略持仓-预览.csv | multi_factor | 最近 5 个交易日持仓 |
| 行业轮动策略持仓-预览.csv | sector_rotation | 最近 5 个交易日持仓 |
| 资金流策略持仓文件-预览.csv | capital_flow | 最近 5 个交易日持仓 |
| 指数增强策略持仓-预览.csv | index_enhance | 最近 5 个交易日持仓 |

## 更新方式

每次发布时，从运行环境 `data/qresult/`（或 `data/holdings/`）取最新持仓，截取最近 5 个交易日生成（保持矩阵格式），替换本目录文件。

> ⚠️ 样例只含持仓数据（股票代码 + 1/空标记），**不含任何 token / 密钥**，可安全提交至 GitHub。
