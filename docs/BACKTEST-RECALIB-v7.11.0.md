> 今后所有经事件引擎产出的绩效数字，方向是**更保守**。本文件给出可复算的差异量化、

## 1. 改了什么

v7.10 在给向量化引擎做 parity 对拍时，发现事件引擎（`strategy_sdk/backtest.py::backtest_holdings`）
有两处真实缺陷，并已修复：

| # | 缺陷 | 影响 |
|---|---|---|
| 1 | docstring 与验收口径都写「t 日收益 × **t-1** 日权重」，实现里 `prev_weights` 只当"非首日"标志，实际参与计算的是**当日**权重 | 前视：相当于提前知道当日收盘后的仓位再吃当日收益，绩效系统性偏乐观 |
| 2 | 换手成本按**全量日期**算好后 `zip` 到**已过滤**的收益序列上 | 只要某日无有效收益（全零持仓/无行情），成本整体错配一格，无收益日越多错得越远 |

修复后：收益改用 `prev_weights`；成本在循环内逐日配对。

## 2. 影响面（谁的数字会变）

| 调用方 | 是否受影响 | 说明 |
|---|---|---|
| `/api/research/backtest`（策略回测工作台） | **受影响** | 直接调用 `backtest_holdings` |
| 参数扫描 `strategy_sdk/sweep.py` | **受影响** | 每组参数都跑 `backtest_holdings`，扫描排序可能变化 |
| 向量化回测 parity | 受影响（已对齐） | 两条链路现在共享同一费率口径，`parity_check` 逐点对拍通过 |
| 回测实验室 `/api/research/backtest-lab` | 不受影响 | `backtest_lab.py` 自带 `lag=1` 独立实现，不调用 `backtest_holdings` |
| 择时 Overlay 研究预览 | 不受影响 | `timing_api._simple_performance` 自带「信号次日生效」口径 |
| 样本内外 `backtest_oos.py` | 不受影响 | 独立实现 |

> 这条很重要：v7.3.0 验收文档里那组线上实测数字（全样本 +1.96% / 年化 +2.77% /
> Sharpe 0.301 / 回撤 -31.21%）来自 `backtest-lab`，**不在受影响范围内**，无需重跑。

## 4. 差异量化（真实行情实测）

样例矩阵（可复算，非任一策略的历史误差）：

- 标的：`600000.SH, 000001.SZ, 600519.SH, 000858.SZ`
- 区间：最近 320 个自然日（真实门户取数，`data_source=realtime`）
- 权重规则：5 日动量 top2 等权，每 5 个交易日调仓
- 旧口径复现：把同一个权重矩阵 `shift(-1)` 后喂给同一向量内核 —— 引擎取 `w[t-1]`，
  移位后恰好取到原矩阵的 `w[t]`，等价于旧实现的"当日权重 × 当日收益"。

| 指标 | 旧口径（当日权重） | 修正（t-1 权重） | 差值 |
|---|---|---|---|
| 区间收益 total_return | +18.80% | **-5.36%** | **-24.16 pp** |
| 年化 annual_return | +12.67% | **-3.75%** | -16.42 pp |
| Sharpe | 0.53 | **-0.38** | -0.91 |
| 最大回撤 | -18.14% | **-30.16%** | -12.02 pp |
| 波动率 | 18.74% | 17.83% | -0.91 pp |
| 胜率 | 50.00% | 47.93% | -2.07 pp |

读法：本例的收益方向直接翻转，因为它的权重来自「当日动量」——旧口径等于"先用当日
涨跌挑股、再吃当日涨跌"，前视红利最大。**具体策略的偏差幅度取决于调仓频率与标的
收益自相关**，不能把这个 24 pp 直接套到别的策略上；能确定的是方向：修正后不会更乐观。

## 5. 后续处置流程（若发现旧口径留存数字）

1. 用当前版本对同一策略/区间/参数重跑（记录 `app_version` 与参数哈希；已锁定的策略先 `verify`）。
2. 新数字**覆盖**旧数字，并在旁标注「口径 v7.11.0 前视修正后重跑」+ 重跑日期。
3. 不要新旧并列而不标注 —— 两套口径混排会让后续比较得出错误结论。
4. 若该结论曾用于对外材料，重跑后同步更正，不做静默替换。

## 6. 复算方法

```bash
# 真实行情（不可用时自动降级模拟并在输出里标注 data_source）
python3 scripts/recalib_backtest.py

# 离线可复现（固定 seed）
python3 scripts/recalib_backtest.py --synthetic --days 320

# 换标的/区间
python3 scripts/recalib_backtest.py --symbols 600000.SH,000001.SZ --days 400
```

输出同时写入 `docs/samples/backtest-recalib-v7.11.0.json`（含 `data_source`、
`archived_experiments` 与 `note`，便于审计复述口径）。
