## 2. 产品概述

### 2.1 定位
面向 A 股的量化决策辅助工具：**美林时钟（宏观周期） × 多策略选股（动量/反转/质量/资金流） × AI 评估（8+ 模型）**，结果集中于日历界面。自 V4.0 起定位为"量化策略研发与运行平台"（个人量化工作台）。

### 2.2 技术栈（当前）
- 后端：FastAPI（Python 3.10+/3.11，CI 3.13）+ SQLite(WAL) + JSON，零外部依赖可部署
- 前端：Vue 3 + Element Plus + ECharts **单文件 SPA，零构建**（改前端需重启后端 + 硬刷新）
- 数据源：sxsc-tushare → tushare → akshare 三源热备自动 fallback
- 双环境：dev(:8001) 开发 | ops(:8000) 生产（cloudflared 公网隧道）；GitHub master 唯一事实源
- 版本节奏：点版本推进，每版本 tag + APP_VERSION 同步

### 2.3 能力清单（V4.0 已建成）
| 域 | 能力 |
|---|---|
| 策略平台 | strategy_sdk 4 内置策略（multi_factor 五维因子 v0.2.0 / sector_rotation / index_enhance / capital_flow）+ 变体 variant / 自定义 custom / AI 代写·优化 / 参数网格扫描 / 因子 IC·分层 / 回测统一 SDK |
| 完全体闭环 | 引擎持仓 data/holdings → 日历 overlay；show_in_calendar 逐策略开关；governance 纳管（内置母本不可改/派生可改） |
| 开放平台 | Webhook HMAC 签名订阅 / API v2 前缀 / 文档站 / 插件机制（样例已加载） |
| 宏观 | 美林时钟四阶段 + 历史周期时间轴（4 轮 18 阶段，tooltip 含本周期 essence + 实时指标） |
| AI | 批量评估 SSE / 智能评估 UI / 厂商化模型管理（密钥掩码 + 密码查看）/ AI 事实护栏 / 复盘 |
| 工程 | 数值 2 位小数 / CI（tag 触发）/ Docker 镜像发布 ghcr.io / 测试 978 用例 / 双端运维 |

## 3. 背景与目标

### 3.1 背景
V4.0 完成"策略研发与运行平台"能力拼图并发布（tag v4.0.0），随后 V4.0.1-4.0.9 完成时间轴 UI 迭代与门禁恢复。
**功能基本完备后，用户决定 4.1-4.5 聚焦程序优化与打磨**，从六个角度系统性评估与改进：美观、适用、逻辑通畅、操作便捷、安全、效率。

### 3.2 六维度评估结论（依据 4 份审计报告，见 docs/audits/）
| 维度 | 关键结论 | 严重度汇总 |
|---|---|---|
| 安全 | 匿名改 admin 密码（账户接管）/ SSRF / 数据刷新匿名 / AI 配置匿名写 / guest 越权 / IDOR / JWT 缺陷 / 默认口令 / 限流可绕过 / 敏感泄露 | P0×4, P1×6, P2×8, P3×5 |
| 美观 | 13 未定义令牌 / dark 426 处硬编码 / 对比度多项 1.25-4.2:1 / 主题冗余 / 品牌漂移 / 字号越界 | 高×4, 中×4, 低×2 |
| 适用 | 研究页空指针崩溃 / 美林入口低 / 配置与展示分离 / 观感待视觉复核 | 高×1, 中×3 |
| 逻辑通畅 | ops 6 键漏注入→3 按钮失效 / loadFactCheck 未定义 / WS 依赖缺失 404 / async 同步阻塞 / 竞态 / 护栏只查数量 | 高×4, 中×6 |
| 操作便捷 | 交互范式不统一 / 登录串行 / 按钮反馈缺失 / 折叠不持久化 | 中×4 |
| 效率 | 年视图 O(n²) 16-21s 冻结全站 / reload 2.5s 同步 / 美林冷 13s / 首屏 60 脚本 / 未登录 9-11 请求 / 轮询浪费 | P0×3, P1×3, P2×4 |

### 3.3 目标（V4.1-V4.5 战略）
1. **安全可信**：消除公网暴露下的账户接管/SSRF/越权路径，鉴权 deny-by-default。
2. **逻辑通畅**：功能断点清零，注入链路有测试护栏，部署依赖完备。
3. **性能达标**：消除单 worker 全站冻结路径；关键接口达到量化指标。
4. **体验专业**：令牌体系完备、对比度达标、主题收敛，界面"专业而非能用"。
5. **工程健康**：巨型文件拆分起步、文档与版本纪律、流程可复跑。

## 4. 用户与核心场景

### 4.1 用户画像
- **决策者（主）**：个人投资者/量化爱好者，每日查看日历选股与 AI 评估，关注宏观周期与策略信号。
- **研究者**：使用策略实验室做因子假设→IC 验证→策略构建→回测→PTrade 导出的研究闭环。
- **运维者**：部署双环境、同步 GitHub、监控数据源与引擎运行。

### 4.2 核心任务流（优化后应保持或增强）
1. 每日：打开日历 → 看今日持仓/信号 → 点入个股详情 → AI 评估 → 决策。
2. 宏观：进入美林时钟 → 看当前阶段 → 悬停历史周期（essence）→ 阶段详情。
3. 研究：策略研究 → 选策略 → 改参/回测/扫描 → 导出 PTrade 代码 → 进日历。
4. 系统：配置数据源/AI 模型/纳管策略/查看用量与审计。
5. 运维：查看健康/指标/审计日志/数据源状态。

#### FR-4.1.2 初始化向导加固（P0）

#### FR-4.1.4 数据刷新鉴权与资源防护（P0）

## 7. 非功能需求（NFR）

### 7.1 性能（V4.5 验收目标）
| 指标 | 现状 | 目标 |
|---|---|---|
| /api/view/year | 16-21s | **<100ms** |
| 冷 merrill 首次 | 13.09s | **<1s**（预热+并行） |
| parser reload 感知 | 2-2.5s 阻塞 | 异步零感知 |
| 首屏脚本请求 | 60 | **≤12** |
| 首屏 WAN TTI | 3-6s | 1.5-2.5s |
| 系统页进入 | ~18s（含 year 冻结） | <1s |
| 全站 P95（无重活） | <50ms | 保持 |
| 后端无效 CPU/写 | 基准 | 降 ~80% |

### 7.2 安全
- 鉴权 deny-by-default；P0/P1 全封或明示豁免；新增端点默认要求登录。
- 密钥/Token 不出明文（掩码统一）；异常不回显内部 detail；默认口令拦截。
- 速率限制按账号 + 真实 IP；暴力登录锁定退避。

### 7.3 可靠性
- 双环境一致（dev=ops=GitHub）；发布有回滚（ops reset --hard origin/master）。
- 数据源不可达明确降级（不假数据）；引擎 20:00 持续产持仓。
- 全量测试全绿 + 门禁；冒烟 0 pageerror 金标准。

### 7.4 可维护性
- 令牌纪律：无硬编码色值（门禁守护）；三向注入护栏。
- 文档三文档同步；版本与 tag 一致。
- 巨型文件逐步拆分。

### 7.5 兼容性与可访问性
- 双主题（浅色/ dark-pro）无样式失效；WCAG 对比度达标。
- 移动端基础可用（375px）；开放缩放。
