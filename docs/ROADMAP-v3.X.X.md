1. **完整用户体系与权限** — 三组权限模型, 多用户隔离
2. **安全基线达标** — JWT/bcrypt/CSP/HSTS/限流/密钥加密

5. **PWA 可安装** — manifest + sw.js 网络优先策略

### v3.2.0 — UI 全面升级 (已有详细规划稿)

**目标**: 从"能用"到"好用", 提升产品质感

阶段 (按 docs/prompts/ui-overhaul-v3.2.0.md):
1. 信息架构: 导航重构 + 面包屑 + 移动端 TabBar + 最近访问
2. 视觉语言: 统一卡片 + 信息层级三件套 + 间距规范 + 空状态
3. 交互效率: 快捷键 + 拼音搜索 + 浮动AI按钮 + 骨架屏
4. 数据可视化: ECharts 主题联动 + 图表提取 + 表格增强 + 美林时钟SVG

**验收**: SPA 完整性 + 三档宽度 + 7主题对比度 ≥ 4.5:1
**风险**: 低 (前端为主, 后端零改动)

### v3.6.0 — 前端渐进式组件化

**目标**: 单文件从 6653 行瘦身到 ~1500 行, 组件可维护 (不引入 Vite/构建链)

**背景**: 全量 SFC + Vite 迁移评估结论为不可行 —
index.html 主 setup() 达 3973 行、154 ref、162 function 高度耦合,
一次性拆分必然失败 (v2.4.0 规划后从未成功)。改为渐进式方案:
保持 CDN + 零构建加载方式, 用 Vue 3 全局组件逐页拆分, 每步可验证可回滚。

| # | 任务 | 说明 |
|---|------|------|
| 3.6.1 | 组件化准备 | 盘点 5 页面与共享逻辑边界, 定义 props/emit 契约, 提取共享状态到 composable |
| 3.6.2 | 拆分 Sidebar/Header | 导航+头部组件化 (改动最小, 先验证流程) |
| 3.6.3 | 拆分 System 页 | 系统设置组件化 (低耦合页面先行) |
| 3.6.4 | 拆分 Strategies 页 | 策略总览组件化 (高耦合页面, 谨慎) |
| 3.6.5 | 拆分 Calendar 页 | 量化日历组件化 (含图表, 最复杂) |
| 3.6.6 | 拆分 AI 页 | AI 评估 + 问股组件化 |
| 3.6.7 | 壳瘦身 | index.html 只保留壳 + 组件注册 + 全局样式引用 |
| 3.6.8 | 冒烟测试 | 每步 SPA 完整性检查 + 浏览器全功能冒烟 (登录→5页面→AI→导出) |

**验收**: index.html ≤ 1800 行; 每步拆分后 SPA 完整性检查通过;
5 页面功能与迁移前逐项对比一致; 零新增 npm 依赖
**风险**: 🟠 中 (保持零构建, 每步独立验证可回滚; 高耦合页面放后面拆分)

## 五、执行顺序建议

1. **v3.2.0 先行** — 规划稿已就绪, 纯前端低风险, 立竿见影
2. **v3.3.0 紧随** — 数据可靠是长期地基, 越早越好
3. **v3.4.0/v3.5.0 并行规划** — 可观测性与 AI 深化不冲突

5. **v3.7.0-v3.9.0 按需** — 依赖外部渠道, 视用户反馈调整
