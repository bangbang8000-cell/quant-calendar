## 2. 目标与范围

### 2.1 目标
- 将 v3.17 交付的"功能完备"推进到"**能力真正跑起来、结论可信、地基健康**"：
  - **激活**：AI 复盘、事件提醒、实时行情、周报胜率等休眠能力接入真实数据源并**持续产出、失败可见**（不再静默）。
  - **可信**：胜率复盘页、因子 IC/IR、回测样本外、AI 事实护栏——决策结论可被验证。
  - **健康**：数据源故障自动切换自愈；全量测试与运行中服务零污染；覆盖率 20%→40%（对齐路线图）；巨型文件二次治理。
- 工程红线：**不引入构建链、不破坏零构建架构**；模块工厂对外签名不变；每阶段结束时全量测试 + 冒烟全绿才可进入下阶段。

### 2.2 范围
- 覆盖 `PRD-v3.18.md` 全部 FR（P0/P1/P2 分级），主线为方向 A（数据闭环落地）。
- 明确**不在本版本**：实时行情 WS 强制落地（数据不可达可顺延且优雅降级）、i18n 全量（维持现状，仅 2 个文件接入不改）、v4.0 完整开放平台。

## 4. 开发计划（分阶段任务）

> 每任务统一四步：**① 写失败测试 → ② 跑通失败 → ③ 实现 → ④ 跑通 + commit**。每任务含：目标 / 改动文件 / 测试 / 验收。

### Phase 3.18.0 — 实·数据闭环落地（P0 主线）

#### T1 数据源健康自动切换与自愈（FR-3.18.4）
- **目标**: 健康状态从"只读仪表盘"变为"自动开关"——主源连续失败切换备用源、恢复后冷却回切、429 不判死、切换写审计 + 面板展示。
- **文件**: `backend/data_sources.py`（路由逻辑 + 冷却窗口 + 计数阈值）、`backend/api/v1/system.py`（路由状态字段）、`frontend/js/components/system-page.js`（健康面板增列）。
- **测试**: 新建 `tests/test_data_source_routing.py`（主源连续失败 N 次→切备用、恢复→冷却后回切、429 不切换、计数阈值边界、抖动抑制）。
- **验收**: mock 主源故障服务无感切换；恢复回切；面板状态正确；审计有切换记录；**TDD**。

#### T2 AI 每日复盘激活链路（FR-3.18.1 核心）
- **目标**: 复盘从"能产出空报告但被记为成功"变为"真实产出 + 失败可见"——16:00 触发 + 三源数据卡 + 归档 + 飞书；**产出判定修正**（关键数据卡字段 indexes/sectors/moneyflow/sentiment 全不可达 → 判定失败，不计为成功）+ **16:30 失败重试一次** + **错过补偿**（服务启动时当日未产出则补跑）+ **连续失败告警**（≥2 次升级，不再静默）。
- **文件**: `backend/market_review.py`（产出判定/重试/产物校验）、`backend/scheduler.py`（失败判定与重试逻辑/任务状态透出）、`backend/api/v1/system.py`（手动触发端点）、`frontend/js/components/system-page.js`（"立即生成复盘"按钮 + 失败状态展示）。
- **测试**: 新建 `tests/test_market_review_activation.py`：
  - 数据可达路径：产物生成完整、数据卡数字来自数据源断言；
  - 数据不可达路径：关键字段全 unavailable → **判定失败**（`_record_task_run=False`）+ 触发告警 + 16:30 重试触发；
  - 错过补偿：启动时当日无归档且已过 16:00 → 补跑；
  - 手动触发端点；调度器注册单测。
- **验收**（双路径）:
  - 数据可达：手动触发可产出真实报告；连续 5 日自动产出无空档；抽查数字非编造。
  - 数据不可达：产出报告标注"数据不可达"且**不被记为成功**；失败可见（告警 + UI 状态）；16:30 重试生效；不抛错、不静默。

#### T3 周报附胜率追踪（FR-3.18.5）
- **目标**: `report_generator.py` 周报追加"本周 AI 评估命中率"小节（总体/分模型/分评级/5-10-20 窗口），未满窗口标注"评估中"。
- **文件**: `backend/report_generator.py`、`backend/eval_track.py`（复用）。
- **测试**: 新增 `tests/test_report_winrate.py`（周报含胜率小节、数字与 eval_track 一致、未满窗口标注）。
- **验收**: 周报胜率与 eval_track 人工抽样一致；未满窗口正确标注。

#### T4 实时行情 WebSocket 激活（FR-3.18.3）
- **目标**: `realtime_quotes.py` 的 `_fetch_from_tushare`（死代码）激活——tushare 实时行情/快照接入 + akshare 回退；自选/持仓盘中报价推送；涨速/量比预警（可达时落地）；不可达发送"数据不可达"状态帧，前端明确占位。
- **文件**: `backend/realtime_quotes.py`（源接入）、`backend/api/v1/market_ws.py`（推送/降级帧）、`frontend/js/watchlist.js`（占位渲染）。
- **测试**: 新建 `tests/test_realtime_ws.py`（mock 源推送、涨速预警计算、不可达降级帧、前端占位断言）。
- **验收**: 可达场景自选股实时刷新 ≤5s；不可达场景 WS 正常连接但标注不可达；不崩不白屏。

> **3.18.0 出口门槛**: 复盘归档 ≥3 条真实报告（连续 3 日或手动补齐）；数据源自愈/WS 优雅降级测试全绿；全量 pytest + 冒烟全绿；`APP_VERSION=3.18.0`。

## 5. 测试计划

### 5.1 测试分层策略

| 层 | 工具/方式 | 覆盖对象 | 执行时机 |
|----|-----------|----------|----------|
| 单元（后端） | pytest（conftest 临时目录隔离） | 数据源自愈/复盘激活/事件源/因子IC/事实护栏/周报胜率/回测真实性 | 每任务 + CI |
| 单元（前端逻辑） | node 调用纯计算核心 | 决策复盘聚合、IC 报告前端聚合 | 每任务 |
| 一致性/静态 | `test_frontend_consistency.py` + deps 审计 + guard | 文件大小 ≤30KB、导出键清单、无新增内联样式、鉴权/主题唯一 | 每任务 + CI |
| 集成（API） | pytest + TestClient | 新端点字段/鉴权/降级/手动触发 | 每任务 |
| e2e 冒烟 | Playwright（`-m e2e`，dev 全跑 + 发布前必跑） | 复盘阅读/事件提醒/决策复盘/因子 tab/实时行情降级 | 每阶段出口 + 发布 |
