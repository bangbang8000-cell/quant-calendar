## 1. 背景与动机

V5.15-v5.16 确立了「中栏列表 + 右栏详情工作区」双栏模式 (通用类 `.detail-split`), 并落地 6 处。2026-09-19 全站盘点发现四类一致性缺口:

| # | 问题 | 走查证据 |
|---|---|---|
| ~~P0-1~~ | ~~模式内部不统一 (两代并存)~~ **已撤销** | **实测更正**: `.shortterm-split` / `.market-review-split` 早已使用 `var(--split-w, 35%)` 且带 `data-split-root` + `data-split-resize`; 浏览器实测宽度 35%、拖拽生效 (35%→548px)、`qc_split_width` 已持久化 —— 与 `.detail-split` 行为一致, **不存在两代问题** (`git blame`: `5d95376b`, 属 `e271f78` v5.17 中栏拖拽调宽) |
| P0-2 | **全局详情模式偏好被无视**: `detailDisplayMode` (内嵌双栏 / 弹窗) 是全局用户设置, 实际仅 3 个页面尊重它; 自选与重点跟踪的个股详情仍强制弹窗 | `watchlist.js:601 showStockKline`、`focus-view.js:341 openStockDetail` 均未读 `detailSplitEnabled` |
| P0-3 | **模板四件套重复 6 处**: `detail-split-wrap` + `detail-split-list` + `split-divider` + `detail-split-pane` 在各页内联, 无统一组件, 新增双栏页需复制粘贴 | grep 6 处重复结构 |
| P1-4 | **强候选页的详情困在弹窗/手风琴**: 美林时钟阶段详情已写好 248 行却只能弹窗; 评估历史/问股历史用行内展开, 列表与详情互相挤占 | `merrill-detail.js`(248 行)、`qc-history-record` 行内展开 |

本版本目标: **不改动业务数据管道与 AI 逻辑**, 把双栏模式收口为统一组件, 并推广到剩余强候选页, 一次性消除「设置不生效」与「两代并存」两类技术债。

## 2. 需求范围 (F1-F6)

### F1: 双栏壳组件抽取 (P0)
- 新增通用组件 `qc-detail-split` (Vue SFC, `frontend/src/components/common/DetailSplit.vue`):
  - props: `enabled` (即 `detailSplitEnabled`)、`listMinHeight`、`paneWidthVar` (默认 `--split-w`)
  - slots: `list` (中栏)、`pane` (右栏工作区)
  - 内部渲染 `.detail-split-wrap[data-split-root]` + `.detail-split-list` + `.split-divider[data-split-resize]` + `.detail-split-pane`
  - `enabled=false` 时: 列表 `w-100` 全宽, 分隔条与右栏不渲染 (保持既有弹窗模式语义)
- 6 处既有双栏改造为使用该组件 (纯重构, 视觉与行为不变)

### F2: 旧式双栏回迁 (P0) — **已撤销**
- **撤销理由 (2026-09-19 浏览器实测)**: 两处旧类双栏本就与 `.detail-split` 行为完全一致 —— 同 `var(--split-w, 35%)` 默认宽、同可拖拽 (实测 35%→548px)、同受 `qc_split_width` 持久化。迁移属纯 churn 且有移动端折叠回归风险, **无用户可见收益**。
- **概念澄清**: 两者是「列表 + 常驻内容」布局 (内容恒在, 移动端上下堆叠), 与 4 处「列表 + 可选详情弹窗」(受 `detailSplitEnabled` 门控) 属**不同布局意图**, 非两代关系。
- **保留**: 两页模板与旧类名均不动; 如后续要求"单一类族", 可另行做零风险 CSS 选择器合并 (非本版本目标)。

### F3: StockList 多选能力 (P0) — **已移除 (2026-09-19, C11)**
- **移除理由**: F4 经决策保留现有自选行结构 (C10), F3 遂失去唯一使用方; 给被 6 处复用的共享组件增加无使用方的 API 面只增回归风险
- 若后续页面 (研究历史 / 回测记录) 需要, 再单独排期

### F4: 我的自选 → 双栏 (P0) ✅ **已完成 (2026-09-19)**
- **实现方式 (按 C10 决策)**: **保留现有自选行结构** (含左滑删除 / 实时报价 / 评分徽章 / 批量复选框), 仅加双栏外壳; 未改用 `qc-stock-list`
- 中栏 (`qc-detail-split #list`): 卡片标题下方依序为 实时报价条 / 搜索添加 / 排序栏 / 自选列表 (虚拟滚动)
- 右栏 (`qc-detail-split #pane`): `qc-stock-detail-dialog :embedded="true"`
- 行点击: `detailSplitEnabled` 时 `showStockDetail(code)` 载入右栏并高亮 (`is-active`); 否则沿用 `showStockKline` 弹窗
- **窄栏两行适配**: 报价块移出行内 `.watchlist-info` 至行级, 双栏时 `flex-basis:100%` 独占第二行; 按钮文案收起为纯图标; 行高 `:row-height` 56→76
- 批量工具栏保留在**双栏之上全宽** (6 个按钮置于 35% 中栏会挤)
- 保留: ≤1024px 强制弹窗; 左滑删除 (`.swipe-reveal`) 与长按复制代码

### F5: 美林时钟 → 双栏 (P0) ✅ **已完成 (2026-09-19)**
- **E1**: `merrill-detail.js` 增 `embedded` prop + 条件绑定 (`append-to-body` / `modal` / `show-close` / `close-on-click-modal` / `lock-scroll` 全绑 `!embedded`) + `qc-embedded-dialog` 条件类 (照 `stock-detail.js` / `index-detail.js` 既有模式)
- **中栏**: 四阶段卡 (双栏时由 2 列网格改竖排列表, 单栏时保持 2 列)
- **右栏**: `qc-merrill-detail-dialog :embedded="true"`
- **自动载入**: 双栏进入美林时, 若右栏无内容则自动载入「当前阶段」详情 (无则首个阶段) — 镜像 V5.16 双栏页的默认选中 watch
- **详情内容零新增** — 248 行详情早已就绪, 本项仅解决「困在弹窗里」
- **范围说明**: 历史周期时间轴 (`merrill-timeline-block`, 108 行) 保留在双栏**下方全宽** (其为聚合可视化, 放入 35% 中栏会挤)

### F6: 重点跟踪 → 双栏 (P0)
- 双栏之上: 日期选择 + 四时段切换 + 五档动作分布条 (照 V5.16.1「移出中栏列表, 置于双栏之上」范式)
- 中栏: 按推荐档位分组的 `qc-stock-list` (保留档位分组头)
- 右栏: `qc-stock-detail-dialog :embedded="true"`
- 双栏之下: 历史记录 + 效果块 保持全宽 (聚合分析, 不随选中股变化)
- 移除: 行内手风琴 `.focus-detail` 与行内「打开详情」按钮的重复入口

## 3. 非目标 (Out of Scope)
- ❌ **旧式双栏类迁移 (原 F2)** — 实测证明无收益, 已撤销 (见 §2 F2)
- ❌ **评估历史 / 问股历史双栏 (原 F7)** — 经评审移入 v5.20, 理由: 批次容量与「每任务 ≤3 文件」纪律 (见 EVAL §3)
- ❌ **回测记录双栏** — `backtest_history.json` 经查仅存 `{sid, ts, summary, params}`, **无净值曲线与交易明细**; 要做出有价值的右栏须先改后端持久化, 超出本版本「纯前端统一」边界 (见 C3)
- ❌ 组合持仓 / 涨停复盘 / 龙虎榜 / 用户与权限 (次级候选: 宽表 8-10 列与 35% 中栏冲突, 或属低频管理页)
- ❌ 板块资金 (4 列排名表, 当前无点击动作, 无详情实体)
- ❌ 表单/工作台页 (量化研究 / 策略管理 / 策略回测 / 基础配置 / 自动评估 / 数据源)
- ❌ 仪表盘页 (智能评估概览 / 研究概览 / 执行看板 / 状态概览 / 用量统计)
- ❌ 日历网格视图 (量化日历 日/周/月/年)
- ❌ 不改动任何业务数据管道与 AI 评估逻辑; 不改动移动端强制弹窗策略
