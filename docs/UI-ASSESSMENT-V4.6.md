# 量化选股日历 美术 UI 全面评估报告 (V4.6)

评估时间: 2026-08-21 (V4.5.0 发布后)
评估方法: 程序化审计(间距/字号/圆角/阴影/动效/令牌) + 代码审查(关键页面) + 专业设计规范(ui-visual-design / Material Design / Apple HIG)
评估基准: V4.4 令牌体系 + V4.5 收尾后的视觉基线 (screenshots/ 双主题 10 图)

---

## 一、总体评价

系统已具备**专业 UI 的核心地基**：完备的令牌体系(裸色仅 3 处)、WCAG 对比度达标、5 主题(含 dark-pro 深色覆盖)、品牌化登录页。
但存在**一致性层面的系统性问题**：间距 42% 违反 4px 网格、动效时长散乱、部分字号/圆角裸值未收敛——这些问题不破坏功能，但使界面"专业感不足"。

**综合评分: 7.2 / 10** (地基优秀, 细节一致性待打磨)

### ❌ 主要问题 (按严重度)

#### P0-1 间距一致性 (严重, 42%)
- **数据**: 999 处间距中 419 处(41.9%)非 4px 倍数
- **分布**: 10px×115 / 6px×89 / 1px×60 / 14px×46 / 2px×45 / 3px×25 / 18px×13
- **影响**: 随机间距破坏视觉节奏, 卡片/区块对齐不齐, 是"廉价感"最大来源
- **规范**: 4px 基准网格 (4/8/12/16/24/32/48)

#### P0-2 动效一致性 (严重)
- **数据**: 66 处 transition, 46 处非令牌(散乱时长 0.15/0.2/0.25/0.3/0.4/0.5/0.8s 混用)
- **影响**: 交互反馈节奏不一, 有的太快有的拖沓
- **规范**: 200ms 过渡 + ease-out, 状态变化才动

#### P1-3 字号裸值 (中)
- **数据**: 20 个字号层级(超规范 4-6 级), 裸值 10px×6/12px×5/11px×3/48px×2 未令牌化
- **影响**: 层级失控, 弱化信息层次

#### P1-4 圆角裸值 (中)
- **数据**: 14px×11/16px×9 等未收敛到令牌(--r-lg/--r-xl 已定义)
- **影响**: 圆角不统一, 部分偏大

#### P1-5 !important 残留 (中)
- **数据**: 266 处(EP 组件覆盖为主, V4.4 已清 dark-pro 105 处)
- **影响**: 部分可清理(非 EP 覆盖), 增加样式维护成本

#### P2-6 tabular-nums 缺失 (低-中)
- **数据**: 0 文件使用(量化数字/涨跌幅/表格)
- **影响**: 数字宽度跳动, 表格列不齐
- **规范**: 数字场景用等宽数字

#### P2-7 卡片密度过高 (低-中)
- **数据**: system-page 106 个 card 类(1285 行), strategies-page 36 个
- **影响**: 界面塞满, 留白不足, 视觉焦点分散

#### P2-8 阴影细节 (低)
- **数据**: 1 处重阴影(0 4px 16px rgba(0,0,0,0.5))非令牌
- **影响**: 个别元素阴影过重

## 三、专业优化建议 (对齐 ui-visual-design)

### 1. 间距系统化 (P0)
- 419 处非 4px 间距收敛到最近 4px 值: 10→8/12, 6→4/8, 14→12/16, 3→4, 18→16/20
- 补 spacing 令牌: --sp-1.5(6px)? 或统一用 4/8/12/16
- 建立门禁: 间距值必须 ∈ 4px 网格或 var(--sp-*)

### 2. 动效系统化 (P0)
- 过渡统一到令牌: --transition-fast(150ms)/--transition-base(200ms)/--transition-slow(400ms)
- 全部 ease-out, 状态变化才动
- 建立门禁: transition 必须用令牌或固定集合

### 3. 排版精修 (P1)
- 字号裸值→令牌: 10px→--font-xs, 12px→--font-sm, 11px→--font-xs, 48px→--font-3xl
- 层级收敛到 8 个令牌以内
- 数字场景加 tabular-nums (涨跌幅/指标/表格/回测净值)

### 4. 圆角/阴影/!important 清理 (P1)
- 14px/16px → --r-lg/--r-xl
- 重阴影 → --shadow-md
- !important 逐段评估: EP 覆盖必需保留, 其他清理

### 5. 组件与留白 (P2)
- system-page 卡片密度优化: 分组/增加 gap/减少嵌套
- 页面视觉焦点强化: 每页一个主视觉区域

### 6. 视觉复核 (收尾)
- 双主题截图对比(优化前后)
- 冒烟 0 pageerror + 全量回归

## 五、风险与说明
- 间距/动效收敛涉及全前端 CSS, 需逐主题验证视觉无回归
- !important 清理需浏览器验证 EP 覆盖仍生效
- tabular-nums 为渐进增强, 不影响现有布局
- 所有改动保持令牌体系(不引入新裸值)
