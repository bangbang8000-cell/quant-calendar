| 项 | 问题 | 修复 | 实测 |

## 2. 按规范逐项评估

### 配色（符合 ✅）
- **中性色主导**：主干/连接线用 --border-strong 浅灰（中性），不抢内容
- **功能色点缀（~10-20%）**：仅阶段 chip 用浅色底+阶段色描边+色点（recovery 浅绿/overheat 浅橙/stagflation 浅粉/recession 浅蓝），当前阶段主色 2px 描边+「当前」徽标
- 深浅主题：chip 浅底固定，深字固定 → 两主题均清晰；tooltip 玻璃分浅(白 0.72)/深(rgba(26,26,62,0.72))两套

### 间距节奏（4px 网格 ✅）
- 周期间距 32、行高 60/120、chip 内 padding 4×10、chip gap 6-8、spine padding-left 26 —— 全部落在 4px 网格

### 布局/对齐（符合 ✅）
- 纵向主干：历史(上)▲→最新(下)▼，方向箭头 + 周期节点圆点 + 左下拐角接续标记
- 每轮内：蛇形折行（n≤4 单行 / n≥5 两行），行2 从右往左，右端短竖线连接
- 连线**测量式精确贴合 chip 中心**（端点误差 0px，仅 L 形拐弯转角为自由点）

### 层级（符合 ✅）
- 连接线在 chip 之下（仅空隙可见）、tooltip 浮层最高（z 40）、chip hover 微提升

### 可读性（符合 ✅）
- chip 文字深灰 #1f2937 对浅底 ≥4.5:1；tooltip 内容 12px/1.6 行高；日期区间 11px 次级

## 3. 仍可继续的美化方向（按收益排序，供选择）

1. **A. 主干/节点升级**：主干竖线改主色渐变或虚线；周期节点做成"圆点+年份"气泡（更醒目轮次标记）——1-2h
2. **B. 当前阶段强调**：is-current chip 加主色外发光（box-shadow 主色 0 0 0 3px + 柔光）——0.5h
3. **C. hover 微动效**：chip 上浮 + tooltip 滑入已实现；可加连线"点亮"（hover 某阶段时其所在轮连线高亮）——1h
4. **D. 阶段条替代 chip**（甘特式连续条）：每轮一条连续时间条按时长分段着色，天然无缝连接（替代 chips+线）——2-3h，改动较大
5. **E. 响应式**：窄屏(<768px)下时间轴横向滚动或卡片堆叠——1-2h

## 4. 结论
时间轴目前符合设计规范、几何精确、深浅色可读、性能轻量（单次 querySelector+几何，MutationObserver+debounce 120ms）。建议：先按需做 A/B 快速增强；D 若追求"更直观的连续性"可后续评估。
