# 05 研究看板

## 行业强度作战矩阵

数据源：同花顺指数目录（320 行业）+ 每行业近 90 日 K 线（5 QPS 令牌桶，约 60 秒拉完，24h 缓存）。

### 指标定义

| 指标 | 公式 | 读法 |
|---|---|---|
| `rel_5 / rel_20 / rel_60` | 行业 N 日涨幅 − **全行业 N 日涨幅中位数** | >0 表示强于行业平均 |
| `acceleration` | `rel_5 − rel_20` | >0 在加速，<0 在退潮 |
| `volume_pulse` | 近 5 日均成交额 ÷ 近 20 日均成交额 | >1 放量 |
| `rank_change` | `rank_5 − rank_20` | 正数表示排名上升 |
| `breadth`（可选） | 成分股上涨家数占比 | 当前成分近似，**不叫指数贡献** |

### 为什么用中位数而不是均值

行业涨幅分布有极端值（单日涨停潮），均值会被拖动。中位中心化后，"强"是相对大多数行业的强，更符合"哪个板块在领涨"的直觉。

### 缺数处理

拉不到历史的行业**不进入结果行**（不会被填 0），而是进入 `failed` 列表并带 reason。

## 热榜—股价共振

问题：热榜排名和股价走势到底同不同向？还是纯情绪？

做法：热榜 TopN 的排名 vs 近 5 日涨幅做 **Spearman 秩相关**。

| 判定 | 条件 | 含义 |
|---|---|---|
| `resonant` | ρ < −0.15 | 越热越涨（同期同向） |
| `decoupled` | \|ρ\| < 0.15 | 热度与股价脱钩（更像纯情绪） |
| `inverse` | ρ > +0.15 | 越热反而越弱 |
| `insufficient` | 样本/方差不足 | 不做结论 |

口径：**同期同向不代表因果**，不能当预测信号；热榜是 TopN 截断，不等于全市场排名。

实测（2026-11-03）：29 只样本 ρ ≈ +0.03 → 判「脱钩」。

## 财务质量分位（v7.3）

六口径（全部由三张报表直接算出，不做模型估计）：

| 指标 | 公式 |
|---|---|
| ROE（摊薄近似） | 归母净利润 ÷ 期末股东权益 |
| 毛利率 | (营业收入 − 营业成本) ÷ 营业收入 |
| 净利率 | 净利润 ÷ 营业收入 |
| 资产负债率（**反向**） | 总负债 ÷ 总资产 |
| 现金流质量 | 经营活动现金流净额 ÷ 净利润 |
| 营收增速 | (本期营收 ÷ 上期营收 − 1) × 100 |

**分位口径**：入参股票池内的样本分位，`meta.percentile` 明确写"不是全市场分位"。

实测：茅台 ROE 32.4% / 毛利率 91.2% / 负债率 16.4%；宁德现金流质量 1.73；银行毛利率为 `null`（无营业成本口径，不填 0）。
