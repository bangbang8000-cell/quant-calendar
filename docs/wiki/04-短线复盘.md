## 三池与合并口径

三池来自"Fuyao 优先 + 本地补齐"的**合并**，不是简单切换：

| 字段组 | 来源 |
|---|---|
| Fuyao 独有（涨停原因 `limit_up_reason`、`continue_day_cnt`、`max_seal_money`、题材串） | Fuyao |
| 本地独有（市值、流通市值、行业） | 本地源补齐（缺市值时经 `daily_basic` 兜底） |
| 重叠字段 | Fuyao 优先 |

每行带 `field_source` 溯源；响应顶层带 `meta`：

```json
{"meta": {"zt": {"source": "fuyao+eastmoney", "include_st": true, "stats": {...}}}}
```

> **口径坑**：涨停家数 `include_st=true` 时是 52 家（含 4 只 ST），东财口径是不含 ST 的 48 家。界面上有「口径 含 ST / 来源」角标，家数与徽标同源，不会打架。

## 指标怎么算

| 指标 | 公式 | 备注 |
|---|---|---|
| 早封率 | 首次封板时间 ≤ 09:30 的占比 | 兼容 `HH:MM:SS` / `HH:MM` / `HHMMSS` |
| 封单留存 | `seal_amount ÷ max_seal_money` 的均值 | 越接近 1 越稳；只统计两字段有效的行 |
| 涨停原因分布 | `limit_up_reason` 按 `+` 切词统计 | **原始词不合并同义** |
| 连板/最高板 | `continue_day_cnt` 统计分级 | 1板/2板/3板+/最高板 |
| 连板天梯 | 近 30 交易日板位 × 日期矩阵 | **样本内**，不可外推 |
| 晋级率 | 天梯逐档估算 | 只能叫"样本内晋级率" |
| 封板率/开板数 | 官方 `limit-up-statistics` | 实测 `seal_rate=0.5926`、开板 33 |

## 情绪脉冲屏（v7.2）

四列卡片：

1. **涨停结构** — 涨停/连板家数、最高板、早封率、封单留存
2. **涨停原因 Top5** — 按 `+` 切词的原始词频
3. **龙虎榜概念 Top5（近 3 日累计）** — 概念等分后的累计净额 + 守恒校验
4. **热榜共振（5 日）** — Spearman 秩相关 + 判定（共振/脱钩/反向）

## 龙虎榜资金拓扑

规则：

1. 只纳入 `range_days=1` 的记录（否则 1 日榜与 3 日榜重复计额）。
2. 一只股票对应多个概念时，**按概念数等分净额**。
3. 无概念的股票进入 `__unmapped__` 桶，**参与守恒**。

硬约束：`Σ概念净额 == Σ股票净额`，容差 1e-6。实测三个交易日 **diff = 0.0（精确相等）**。

## 数据源不可用时

关闭 Fuyao 后实测：

- 三池 / 龙虎榜 / 情绪脉冲 → 走本地兜底，仍可用
- 热榜 / 异动 / 快讯 / 财务 → `capability_disabled` + reason，不伪造数据
