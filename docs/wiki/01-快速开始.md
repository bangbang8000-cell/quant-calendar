# 01 快速开始

## 环境要求

| 项 | 要求 | 备注 |
|---|---|---|
| Python | 3.10+ | 本机实测 3.14 |
| 内存 | ≥2 GB | 建 DWH 全量面板时峰值较高 |
| 磁盘 | ≥3 GB | DuckDB 面板约 542 MB + 备份 7 份 + Parquet 归档 |
| Node | 不需要 | `frontend/dist` 已入库，部署免构建 |

## 方式一：源码（7.x 当前推荐）

```bash
git clone https://github.com/bangbang8000-cell/quant-calendar.git
cd quant-calendar
pip install -r requirements.lock          # 只读环境: pip install --target=<ws>/qc_ws_pkgs -r requirements.lock
cp .env.example .env                      # 填入 TUSHARE_TOKEN 等
python -m uvicorn backend.main_new:app --host 0.0.0.0 --port 8000
```

打开 <http://127.0.0.1:8000>，健康检查：`curl http://127.0.0.1:8000/api/health` → `{"status":"ok","version":"7.3.0"}`。

## 方式二：Docker

镜像只对**关键版本**（`x.y.0`）构建，当前可用标签 `6.6.0`：

```bash
docker pull ghcr.io/bangbang8000-cell/quant-calendar:6.6.0
docker run -d --name quant-calendar -p 8000:8000 \
  -v "$PWD/data:/app/data" -v "$PWD/.env:/app/.env:ro" \
  ghcr.io/bangbang8000-cell/quant-calendar:6.6.0
```

## 必配环境变量

| 变量 | 必需 | 作用 |
|---|---|---|
| `TUSHARE_TOKEN` | ✅ | 主数据源；缺失会导致行情/日线大面积降级 |
| `SXSC_TUSHARE_TOKEN` | ⬜ | 首选源，缺失自动走 tushare |
| `FUYAO_API_KEY` | ⬜ | 同花顺平台；**只从环境变量读，不写配置文件** |
| `IWENCAI_API_KEY` | ⬜ | 涨停原因补充（v6.8 起 Fuyao 优先） |
| `SECRET_REVEAL_PASSWORD` | ⬜ | 系统页查看完整密钥时的解锁口令 |

## 首次登录后要做的事

1. **改默认密码**（弱口令会触发告警：系统页会提示真实命中的账号）。
2. 系统配置 → 数据源：确认 `TUSHARE_TOKEN` 显示为掩码且状态为已连接。
3. 系统配置 → 同花顺（可选）：填 Key 后点「测试连接」，再看能力矩阵是否全部为绿。
4. 若要用研究看板/DWH：见 [06 数据底座 DWH](06-数据底座DWH.md) 建本地面板。

## 目录与数据

```
data/            ← 运行数据（.gitignore，不入库）
  app.db         ← 用户/自选/组合等
  dwh/market.duckdb      ← 全市场面板（约 542 MB）
  dwh/backup/            ← 每日备份，保留 7 天
  dwh/archive/           ← 最新 1 份全量 Parquet（复现用）
```
