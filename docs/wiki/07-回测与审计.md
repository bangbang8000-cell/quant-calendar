# 07 回测与审计

## 回测实验室做了什么

`GET /api/research/backtest-lab?lookback=20&top_k=10`

流程：

1. 从本地 DuckDB 取 `v_daily_qfq` 面板（可按 `start` 截断）
2. t 日收盘计算动量得分 → 选 TopK
3. **收益从 t+1 起计**（`lag=1`）
4. 换手按双边成本扣减（佣金 + 滑点 + 卖出印花税）
5. 按时间顺序切样本内（前 70%）/ 样本外（后 30%），**同一套参数**各自回测

## 为什么"不好看"

实测（ops，2026-01-05 → 2026-11-03，面板 1,099,796 行）：

| 区间 | 总收益 | 年化 | Sharpe | 最大回撤 |
|---|---|---|---|---|
| 全样本 | +1.96% | +2.77% | 0.301 | −31.21% |
| 样本内 | +0.19% | — | — | — |
| **样本外** | **−23.0%** | — | — | — |

这个窗口里 20 日动量策略基本是亏的。产品**没有**换参数把它调好看——样本内外同一套参数，衰减就展示衰减。

## 指标定义

| 指标 | 定义 |
|---|---|
| `total_return` | 日收益连乘 − 1 |
| `annual_return` | 按 252 交易日年化 |
| `sharpe` | 日均值 / 日标准差 × √252 |
| `max_drawdown` | 净值相对历史峰值的最小值 |
| `win_rate` | 日胜率 |
| `turnover` | 换手累计（买卖权重之和） |

## 防未来函数：五项可执行审计

`GET /api/research/pit-audit`，或 `pit_audit.audit()`。

| 检查 | 判据 | 失败含义 |
|---|---|---|
| `dwh_freshness` | 库内最新交易日 ≤ 目标日 | 用了未来数据 |
| `factor_lag` | 复权因子最大日期 ≤ 目标日 | 因子穿越 |
| `panel_columns` | 面板字段不得含 `future_/next_/fwd_/label_` 前缀 | 标签泄露 |
| `watchlist_pit` | 入参日期全部 ≤ 目标日 | 自选/回测穿越 |
| `export_footer` | 导出物有四要素尾注且无禁称 | 交付物不合规 |

两条设计原则：

1. **"跳过 ≠ 通过"**：前提不满足（无库/无入参）时 `ok=true` 但带 `skipped=true`，`meta` 里明写"不代表已验证"。
2. **审计自身不许炸**：库坏了、模块缺失，都转成 `failed + detail`，而不是抛异常。

实测（2026-11-03）：5 项全通过，`passed=true`。

## 零源演练

关掉某个数据源后产品还能不能用？用脚本验，不靠猜：

```bash
# 进程内（CI 每次跑）
pytest tests/test_zero_fuyao_drill.py -q

# 实机（ops）
python3 scripts/drill_zero_fuyao.py --base http://127.0.0.1:8000 --token <jwt>
# 若开关已由带外（改配置+重启）关闭：
python3 scripts/drill_zero_fuyao.py --base http://127.0.0.1:8000 --token <jwt> --skip-toggle
```

判定口径：

| 类别 | 期望 |
|---|---|
| 核心行情 / 日历 | 必须可用（本来就不走 Fuyao） |
| 三池 / 龙虎榜 / 行业强度 / 脉冲 | 本地兜底可用 |
| 热榜 / 异动 / 快讯 / 财务 | `available=false` + `reason`（诚实降级） |
| admin 端点 403 | 跳过，不算失败 |

实测结论：通过（14 个端点）。
