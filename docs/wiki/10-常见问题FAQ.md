# 10 常见问题 FAQ

## 数据与来源

**Q：为什么核心行情不能走同花顺？**
A：核心口径一旦换源，历史数据会在某天悄悄变形（复权方式、成交量口径）。产品选择"T1 只认稳定的三源"，把新源放在周边做增量。代码里 `T1_FORBIDDEN={'fuyao'}` 是硬过滤，不是文档约定。

**Q：涨停家数到底几家？页面上为什么写"含 ST"？**
A：同花顺涨停池含 ST（实测 52 家，其中 4 只 ST），东财口径不含 ST（48 家）。两个数都对，但**不能混用**。界面上有「口径 含 ST / 来源」角标，家数与徽标同源。

**Q：龙虎榜为什么有时少于上游返回的条数？**
A：只纳入 `range_days=1` 的记录。上游同时给 1 日榜和 3 日榜，若都算，净额会重复计。实测某日 88 条里排除 28 条 3 日榜，剩 60 条。

**Q：异动解读为什么一次返回几百条？**
A：上游该接口**忽略 `page/size`**，一次返回当日全量（实测 473 条）。所以分页在本地做：全量拉一次并缓存，按页切片，翻页不再请求上游。

**Q：财务分位是全市场分位吗？**
A：**不是**。全市场分位要 5500×3 次请求，超配额。我们算的是"你传进来的这批股票池内的样本分位"，`meta.percentile` 里写明「不是全市场分位」。

## 口径与文案

**Q：为什么页面老强调"不是投资建议"？**
A：这是产品纪律的一部分：所有涉及口径的文案都要有「数据时间 / 来源 / 口径 / 非投资建议」四要素，导出物缺一即不合格。有自动化守护（`backend/disclosure_terms.py`）。

**Q：那我可以在自己的报表里写"该板块贡献指数 3 个点"吗？**
A：如果数据来自本项目，禁止（会被守护拦下）。我们只有"等权涨跌代理"，没有权重数据，写"贡献"就是编造。

**Q：回测结果这么差，是不是代码有 bug？**
A：不一定。实测 2026 年 20 日动量策略全样本 +1.96%、样本外 −23.0%。回测框架本身有 8 个测试守着（lag=1、成本侵蚀、指标数学、时间切分），亏是策略在该窗口亏，不是算错。要找 bug 可以看 `tests/test_backtest_lab.py` 覆盖了哪些性质。

## 部署与运行

**Q：启动就报错，说 `.env` 里有多余字段？**
A：配置是严格模式（`extra=forbid`）。`.env` 里出现的字段必须在 `config.py` 里声明。加新变量前先加字段声明。

**Q：DWH 一定要建吗？**
A：不必。它只做加速与研究。不建的话研究接口走逐票（慢），回测实验室返回 `dwh_unavailable`。

**Q：`data/dwh/market.duckdb` 能直接拷到另一台机器吗？**
A：可以，同版本 DuckDB 直接打开即可。这也是最省事的迁移方式（约 542 MB）。

**Q：镜像为什么停在 6.6.0？**
A：Docker 只对关键版本（`x.y.0`）构建，且保留最近 10 个。7.x 目前以源码部署；要出镜像需对 `v7.3.0` 这类 tag 触发 workflow（注意门禁只认 `.0` 结尾的 tag）。

**Q：端口冲突 / 想换端口？**
A：`uvicorn ... --port 8001`，并同步修改服务单元与前端代理配置。

## 开发

**Q：改了前端为什么页面没变？**
A：`frontend/dist` 是入库产物，后端只 serve 它。改 `frontend/js` 后需要 `cd frontend && npx vite build`。

**Q：提交时对拍快照测试红了？**
A：两种可能：① 你无意改变了渲染（要修）；② 你有意改 UI（用 `QC_PARITY_REGEN=1 pytest tests/test_behavior_parity_630.py` 重建，并在提交信息里说明"有意变更"）。

**Q：源码体积预算红了怎么办？**
A：已经到最后一次上调（1.60 MB）。正确做法是先做优化（模板改计算属性 + `v-for`、复用宿主格式化函数、去重复实现），再考虑**拆分懒加载组件**，不要直接改预算数字。

**Q：单文件超 700 行怎么办？**
A：拆域（参照 `logic-tour.js` / `logic-sentiment.js` 的装配模式），而不是加注释分区。

## 我该从哪里开始读代码？

按这个顺序最省时间：

1. `backend/data_tier.py`（分层与过滤，理解"为什么"）
2. `backend/shortterm/fetchers.py`（合并与兜底，理解"怎么取"）
3. `backend/dwh/adapter.py`（本地面板入口，理解"怎么快"）
4. `backend/research_export.py` + `backend/disclosure_terms.py`（口径守护，理解"怎么诚实"）
5. `tests/test_backtest_lab.py`（看一个模块的测试该怎么写）
