# PRD-v5.18: UI 基础体验硬化 (非交易日模式 / 语义色统一 / 空态错误态统一 / 主色降噪)

> 版本: v5.18 里程碑 (APP_VERSION 建议 5.8.0)
> 状态: 待批准 → 已批准
> 创建: 2026-09-19
> 前置: v5.17.3 (全站文字/字体/字号/颜色优化) (详情内嵌双栏) 已交付; 中栏美术优化 (复盘日历/每日复盘 选中态+涨跌色+情绪色阶) 已在本地完成
> 评估依据: 2026-09-19 全站 UI 走查 (策略总览/美林时钟/大盘行情/策略共识榜/短线复盘五子页/系统状态, 浅色+深色+6 主题色)

## 1. 背景与动机

v5.15–v5.16 完成了双栏交互模式的落地。2026-09-19 全站走查发现**基础体验层**存在四类系统性问题, 不解决会持续放大后续页面开发的一致性债:

| # | 问题 | 走查证据 |
|---|---|---|
| P0-1 | **非交易日误导**: 周六/周日全应用展示旧交易日数据, 仅各处散落小标签"非交易日", 用户易误以为实时 | 首页"最新交易日 2026-09-11 · 0秒前刷新"、每日复盘"历史交易日"、系统状态三处口径不一 |
| P0-2 | **语义色未统一**: 红涨绿跌只在表格里用, 指标卡/进度条/情绪分/状态竖条颜色各自为政 | 今日一屏 4 卡左侧竖条蓝/绿/金/红无语义; 中栏赚钱效应此前大量"—"无色 |
| P1-3 | **空态/错误态三套文案**: "暂无已抓取日期" / "暂无市场复盘" / "加载失败, 请稍后重试" 风格不一 | 板块资金页整页错误态朴素; 每日复盘空列表与短线复盘空列表样式不同 |
| P1-4 | **主色铺底过满**: 金色侧边栏/顶栏/选中态大面积使用, 深色+品红主题时进度条过亮 | 深色模式下品红进度条全屏抢眼; 侧边栏底色应为中性 |

本版本目标: **不动业务功能, 只硬化 UI 基础层**, 让后续页面开发有统一的语义令牌与状态组件可依赖。

## 2. 需求范围 (F1-F5)

### F1: 非交易日全局提示条 (P0)
- 顶栏下方新增**全局提示条** (琥珀色背景 `--qc-warn-bg`, 左侧图标):
  - 交易日 09:00 前 / 15:00 后 / 周末 / 节假日 → 显示: "今日非交易日, 展示最近交易日 YYYY-MM-DD 数据"
  - 交易日盘中 → 不显示
- 提示条可关闭 (本次会话内, localStorage 记忆)
- 全局"数据时间"胶囊统一到顶栏右侧 (原首页/每日复盘/系统状态三处分散提示收敛为一处)
- 非交易日时: 自动刷新逻辑暂停 (已有调度, 仅前端不触发手动刷新抖动); "生成/刷新"按钮 tooltip 提示"将基于历史数据"

### F2: 语义色统一 (P0)
- 在 `tokens.css` 固化语义令牌 (已存在 `--qc-market-up/down/neutral`, 扩展为完整四态):
  - `--qc-up` / `--qc-down` / `--qc-neutral` (涨跌, A股红涨绿跌)
  - `--qc-success` / `--qc-error` / `--qc-warn` / `--qc-info` (状态四色)
- 全站替换散用硬编码色:
  - 今日一屏 4 卡左侧竖条 → 仅在"有环比变化"时用 up/down, 纯装饰卡片去掉竖条
  - 指标卡图标底色 → 按语义 (success=绿 / info=蓝 / warn=橙 / neutral=灰)
  - 中栏情绪分色阶沿用 v5.16 本地已做的 `meta-emotion-hot/cold` (≥0.8 红 / <0.6 绿)
- 深色模式下所有语义色自动降 15% 饱和度 (在 `[data-theme="dark"]` 覆盖)

### F3: 空态/错误态组件统一 (P1)
- 收敛 `qc-state-panel` 文案为三类:
  - 空态: "暂无 X" (图标 + 标题 + 可选主操作)
  - 加载失败: "加载失败, 请重试" + 重试按钮 + "复制错误信息"
  - 加载中: 统一 spinner
- 统一错误态布局: 居中卡片 (图标 48px + 标题 + 描述 + 操作区), 板块资金页错误态套用此组件
- 日期列表空态 ("暂无已抓取日期" / "暂无复盘日期") 复用同一样式

### F4: 主色降噪 (P1)
- 侧边栏底色: 浅色 `#faf8f3` (微暖中性) / 深色 `#0f172a` (近黑), 去掉整片金色
- 顶栏底色: 与侧边栏同色系, 主色只留在:
  - 当前 tab 下划线
  - 选中导航项左边条
  - 主按钮 (生成/登录)
  - 关键数字强调
- 主题色选择器保留 6 色, 但默认"跟随"系统时侧边栏不染色

### F5: 中栏优化入版本 (已完成, 记录)
- 复盘日历 / 每日复盘中栏: 选中态金色左边条+日期变金、赚钱效应红涨绿跌、情绪分强弱色阶、meta 行标签弱化 (已在本地 dev 完成, 本次纳入版本验收)

## 3. 非目标 (Out of Scope)
- ❌ 不改动业务功能 (双栏模式/AI 评估/K线/数据管道)
- ❌ 不做二级 tab 竖向锚点改造 (发现性, 后续版本)
- ❌ 不做数字等宽对齐/卡片栅格自适应 (P2, 后续)
- ❌ 不做深色模式全量对比度走查 (P2, 后续)
- ❌ 不做"只看有数据"筛选 (P3, 后续)
