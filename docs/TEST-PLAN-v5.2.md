## 2. 各版本测试资产

### 2.1 V5.2.0（数据基座）约 +60 用例

- 涨停/炸板/跌停三池：字段映射、代码补零、降级 fallback（东财→同花顺→tushare）
- 涨跌幅制度感知边界：10cm/20cm/北交所 30cm/ST 5%、一字板、尾盘炸板（`_limit_ratio` 口径）
- 连板梯队/断层：空档检测、最高板、跨题材口径标注
- 交易日历/定稿：`is_settled` 判据、参考股推导、盘中不把未定稿当定稿
- 迁移 0004：幂等建表、可回滚、备份兼容、重复执行无副作用
- API：三池/梯队/龙虎榜/板块资金端点 + deny-by-default 鉴权
- 前端一致性：菜单注册、子页中文名、懒加载 chunk

### 2.2 V5.2.1（情绪指标与盘面）约 +80 用例

- 赚钱效应：均值 vs 中位数背离、翻红率/再涨停率、**覆盖率闸门**（<50% 不可用/<90% partial）、定稿优先 vs 实时兜底路径
- 晋级率：1进2/2进3/3板+ 分档、只比对两天池子不需实时行情
- 连板溢价、梯队断层
- 情绪周期：minmax 归一化、全相等给 0.5、炸板率缺失按窗口均值补、相对读数标注
- 明日验证条件：eps 阈值（40→41 不算上升）、三态核验（成立/证伪/None）、基准发生率与超额、用户自设覆盖 AI
- 历史分位/日环比/趋势：缓存文件指纹（mtime+size）触发重算，不锁死"当天未落盘"

### 2.3 V5.2.2（AI 复盘与闭环）约 +90 用例

- 多分析师编排：单角色失败降级不炸链、配置错误不降级直接冒泡、失败信封识别
- 裁判：JSON 骨架 + pydantic 校验（档位归一化）、markdown 渲染、重试降级链（JSON→重试→自由文本→安全占位）
- 反思闭环：三路投票判情绪走向、次日自动核验、战绩记分板、历史命中注入（mock LLM）
- 盘中核验：6 时点快照、过点 8 分钟拒绝、历史日绝不现抓、休市不抓、上海时区（跨时区机器照常）
- 涨停样本统计：分情绪环境、窗口 20/30/60/90、样本偏差声明、无前视
- 归档/漂移：raw 标志位（归一化检不出漂移如实说明）、字段漂移、结构漂移（近10 vs 前20 中位数比较）、制度日历人工登记（绝不从数据反推）
- AI 成本：日级同题缓存、用量限制生效、可配置关闭

## 3. 数据诚实性守卫测试清单（PRD §5 十条 → 测试）

| # | 纪律 | 守卫测试形态 |
|---|---|---|
| 5.1 | 空数据≠0 | 取数失败返回 `available:false` + reason，断言**绝不等于 0 家**；判据 `is not None` |
| 5.2 | 失败统一信封 | 所有降级返回带 `[⚠️ ...]` 前缀，降级判定只认此前缀 |
| 5.3 | 覆盖率闸门 | 覆盖率 <50% 整体不可用、<90% 标 partial，prompt/UI 提示样本不全 |
| 5.4 | 定稿优先 | 昨日涨停股表现优先定稿记录；实时仅目标日=最近已收盘场次兜底 |
| 5.5 | 实时不冒充 | 快照过点 8 分钟拒绝；历史日绝不现抓；涨停池钉住已收盘场次 |
| 5.6 | 涨跌幅制度感知 | 20cm 跌 12% 不算跌停；ST/北交所/科创板各自判定 |
| 5.7 | unavailable 标注 | 每个输出 `available`+`reason`；验证条件数据不足=`None` 不算判错 |
| 5.8 | 口径如实披露 | 情绪周期标"十日相对读数"；梯队断层标"跨题材"；板块资金历史场次标"实时口径" |
| 5.9 | 原始归档 | 归档断言存**原始行**（raw=true），归一化行检不出漂移要如实说明 |
| 5.10 | 制度人工登记 | 制度变化只从人工日历读，**从数据反推制度变化 = 测试失败** |

> 借鉴 vibe-astock：这些是"错了也看不出来"的地方——界面照常渲染、数字看着合理，但结论是错的。必须用测试锁死。

## 4. 专项验证

| 专项 | 内容 |
|---|---|
| 无前视 | 样本统计/情绪周期/验证条件不得引用 `as_of` 之后的行情；断言 `end <= as_of` |
| 原子写 | 归档/快照/复盘产物 `tmp+os.replace`，并发读 10 轮无半截文件 |
| 并发 | scheduler 与手动触发并发写不丢单；快照调度单飞 |
| 降级路径 | 三源全挂/DB 只读/涨停池缺失 → 复盘仍可降级产出，界面如实标注 |
| 数据源漂移 | 字段清单变化 → 漂移报告，归档可检测性（detectable）如实 |
| 缓存新鲜度 | 按已收盘交易日过期（非自然日）；补数据触发重算 |
