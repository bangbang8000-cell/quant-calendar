| 2 | 动作体系 | **5 档**：买入 / 持有（已持仓） / 观望（未持仓） / 减仓 / 卖出；**动作 = 评分/level × 用户持仓状态** 派生（见 §1 FR-5.4.7） |

### 0.1 一句话定位

5.4 = **重点跟踪评估**：对「自选 ∪ 每日新入池」两个小集合（约 20-70 只）做**盘前/盘中/盘后多时点精准评估**；推送**精简 digest**（5 档动作|评分|方向）；**程序界面展示并长期存留历史记录**；以**准确性评估**驱动评估逻辑持续优化。全程守「评估/参考」合规措辞，不构成投顾荐股。

### 0.2 收敛过程（原始三条用户诉求 → 本版）

| 原始诉求 | 收敛结果 |
|---------|---------|
| 买卖信号平民化（三值卡） | 收敛为精简推送 digest 与界面行式：每股一行「动作|评分|方向」；动作细化为 5 档（含持仓感知的持有/观望） |
| 更高频数据（60min/5min/1min…） | 收敛为**评估更频繁**（多时点评估重点清单）；分钟 K 线降级为 5.4.2 可选的评估输入，**不产日内交易信号** |
| 300 只精品股集合 | 收敛为**动态重点清单 = 自选 ∪ 每日新入池**，零人工维护、天然小集合 |
| （新增）界面展示与历史存留 | 程序界面展示当日多时点结果 + 历史记录浏览；评估结果结构化落库长期保留 |
| （新增）准确性评估 | 历史命中率/动作兑现率/分桶校准/分模型命中率 → 置信度与优化建议 → 反哺评估逻辑 |

### 0.3 设计原则

1. **对象收敛**：只评估用户关心的股票（自选∪新入池），不铺全市场，数据/算力/AI 成本可控。
2. **频次×对象绑定**：多时点 × 小清单。盘前 + 盘后必做，盘中可选（成本开关，默认关）。
3. **数据留痕优先**：一切评估结果先结构化落库（focus_evals 表），界面/推送/准确性分析共用同一份数据。
4. **持仓感知动作**：同一评估结果，按「是否已持仓」派生不同动作（未持仓→买入/观望；已持仓→持有/减仓/卖出），贴近真实持仓决策。
5. **准确性闭环**：不拍脑袋给分——置信度 = 动作×评分分桶的历史命中率；准确性报告输出阈值/模型/权重优化建议。
6. **合规措辞**：动作词为「参考动作」，推送与界面均附「历史命中率不代表未来收益」免责声明。

### 0.4 边界（本版明确不做）

| 不做 | 原因 |
|------|------|
| 全市场分钟级信号 / 秒级策略 | T+1 制度 + 成本吞噬 + 噪声 + L2 数据费，三重否决 |
| 固定 300 只人工精选池 | 人工筛选不可复现、需 PIT 时点化、有换池偏差；动态清单更优 |
| 投顾式「买入/卖出」指令 | 触碰证券投资咨询牌照红线 |
| 自动实盘下单 / API 交易执行 | 不在本产品范围 |
| 新增第三方依赖 / 前端构建链 | 保持零依赖、零构建 SPA 架构 |

## 1. 需求分解（FR）

### FR-5.4.1 重点跟踪清单
- 动态清单 = 用户自选（watchlist 表）∪ 每日新入池（calendar 视图 status=new，20:00 策略生成后计算）
- 开关：全量（默认）/ 仅自选 / 仅新入池；清单可查询（数量、成员、来源标注）
- 验收：清单计算正确（并集、去重、来源标注）；开关持久化

### FR-5.4.2 多时点评估
- 时点（已锁定）：盘前 09:00（含昨日新入池）、盘后 20:00（当日策略生成后，**必做**）；盘中 10:30/14:00（可选开关，默认关）
- 评估方式：批量 AI 评估（复用 batch-evaluate/stream）；AI 不可用或清单过大时降级为**规则因子快评**（非 LLM，如实标注 method=rule）
- 结果按 (日期, 时段, 股票) 落库（客观评估结果，同一股票只评一次）
- 验收：调度按时点触发；过点拒绝；历史日不现抓；降级如实标注；幂等

### FR-5.4.3 历史记录存留
- 新增 SQLite 表 focus_evals（migration _0007），字段见 §2；**只存客观评估事实，动作不入库**
- 保留期 ≥ 2 年（数据量小，年约 7 万条）
- 与 ai_evaluation_history（用户 JSON，500 条上限）并存
- 验收：落库可查、跨重启保留、测试隔离（patch_data_dir）

### FR-5.4.4 界面展示
- 新「重点跟踪」子 Tab（AI 页内，已锁定）：
  1. **今日概览卡**：日期 + 时段 + 清单数 + 5 档动作分布（买入/持有/观望/减仓/卖出）
  2. **当日多时点结果**：每股一行（5 档动作|评分|方向），行点击展开详情（9 维评分/买卖点/归因/数据时效）
  3. **历史记录**：按日期浏览历史评估，支持时段筛选，同一股票不同时点/不同日期变化对比
  4. **效果块**：历史命中率 n5/n10/n20（复用 eval_track/winrate）+ 样本量标注 + 免责声明
- 验收：四块可访问；动作按当前用户持仓派生；空态/加载态/错误态友好

### FR-5.4.5 精简推送
- 推送对象：重点清单 digest（5 档动作），格式见 §3（统一 emoji/代码/计数口径）
- 渠道（已锁定）：飞书 webhook，text + interactive 卡片双模（复用 FeishuPusher 扩展）；webhook 通用
- 触发（已锁定）：默认盘后 20:15 定时 + 手动（系统页按钮/API）
- 验收：推送文本与 §3 模板逐字一致（符号/代码/计数）；发送成功/失败可感知

### FR-5.4.6 准确性评估（用于优化评估逻辑）
- 指标（基于落库历史 + 行情兑现，复用 eval_track 数据层）：
  1. 方向命中率：看多→后 n5/10/20 交易日上涨比例；看空→下跌比例（已有）
  2. 动作兑现率：买入→后 n5/10/20 正收益比例；减仓/卖出→负收益比例（新增）；持有/观望按「维持不动」的收益比较
  3. 评分分桶校准：score 分桶（80+/70-79/60-69/60 以下）→ 实际正收益概率
  4. 分模型命中率：provider 维度命中率对比 → 模型路由建议
  5. 分维度贡献（可选）：signal_attribution 各维度得分与结果相关性 → 权重优化建议
- 输出：准确性报告（页面展示 + 可导出）；如实标注样本量，样本 < 30 标注「样本不足」
- 验收：各指标计算正确；与既有 eval_track 测试不回归

### FR-5.4.7 置信度与优化反馈闭环 + 5 档动作派生
- **5 档动作派生表**（focus_action_map，单一实现；holding = 该用户是否持仓该股）：

| 评分/level 桶 | 未持仓（观望系） | 已持仓（持有系） |
|---------------|----------------|----------------|
| 强烈推荐 | 买入 🟢 | 持有 🟡 |
| 推荐（score ≥ 60） | 买入 🟢 | 持有 🟡 |
| 谨慎推荐 / 中性（40 ≤ score < 60） | 观望 ⚪ | 持有 🟡 |
| 看空/弱（30 ≤ score < 40） | 观望 ⚪ | 减仓 🟠 |
| 深看空（score < 30） | 观望 ⚪ | 卖出 🔴 |

- holding 数据源：用户 portfolio_positions（已有持仓模块）；无持仓记录默认未持仓
- 置信度 = 动作×评分分桶的历史命中率（v1 直接映射；v2 可选 Brier 校验，不达标降级显示「低」）
- 置信度展示：推送 digest 摘要行 + 界面每股行
- 优化建议输出（人工确认后应用）：动作阈值调整、模型路由、维度权重
- 验收：5 档派生正确（含持仓/未持仓全组合）；置信度分桶正确；建议以报告形式给出

## 2. 数据与存储设计

focus_evals 表（migration _0007，SQLite WAL；**只存客观评估事实**）：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT PK | 评估记录唯一 id |
| trade_date | TEXT NOT NULL | 交易日期 YYYY-MM-DD |
| session | TEXT NOT NULL | 时段: pre_open / intraday_1 / intraday_2 / after_close |
| stock_code | TEXT NOT NULL | 6 位码 + 后缀 (601985.SH) |
| stock_name | TEXT | 股票名 |
| total_score | REAL | 评分 0-100 |
| level | TEXT | 原五档 level（强烈推荐/推荐/谨慎推荐/中性/观望） |
| direction | TEXT | 看多 / 震荡 / 看空（由 level 派生） |
| model_provider | TEXT | 评估模型来源（AI provider / rule） |
| model_used | TEXT | 具体模型 |
| raw_json | TEXT | 完整评估原始结果（9 维/买卖点/归因/时效） |
| created_at | TEXT NOT NULL | 落库时间 |

索引：idx_focus_date_session (trade_date, session)；idx_focus_stock_date (stock_code, trade_date)。
**动作不入库**：5 档动作 = f(total_score, level, 用户持仓) 在查询/推送时按用户实时派生（单一实现 focus_action_map）。保留 ≥ 2 年全量，随既有备份流程。

## 3. 推送格式规范（统一口径）

**统一符号表**：动作 = 买入(🟢) / 持有(🟡) / 观望(⚪) / 减仓(🟠) / 卖出(🔴)；代码统一 6 位+后缀；计数与行内动作同源同词。

推送文本模板：

    股票智能分析报告
    🎯 {YYYY-MM-DD} 决策仪表盘

    💬 共分析 {N} 只 | 🟢买入:{b} 🟡持有:{h} ⚪观望:{w} 🟠减仓:{r} 🔴卖出:{s}
    市场状态：{A股 · 盘前/盘中/盘后/已收盘}

    📊 分析结果摘要

    🟢 中国核电(601985.SH): 买入 | 评分 67 | 看多
    🟡 迈瑞医疗(300760.SZ): 持有 | 评分 66 | 看多
    ⚪ 中兴通讯(000063.SZ): 观望 | 评分 48 | 震荡
    🟠 华大基因(300676.SZ): 减仓 | 评分 33 | 看空
    🔴 永鼎股份(600105.SH): 卖出 | 评分 28 | 看空
    （按动作档位降序 + 评分降序；行数上限可配，默认 20）

    ⚠️ 历史命中率不代表未来收益，仅供参考，不构成投资建议。

说明：动作含持仓感知（持有=已持仓、观望=未持仓）；代码统一带后缀；计数与行内动作一致。市场状态复用 shortterm /latest-session。

## 5. 准确性评估与优化闭环（FR-5.4.6 / 5.4.7）

- v1（5.4.1）：置信度分桶 + 准确性报告 + 优化建议（人工确认）

- 纪律：任何基于历史结果调整评估逻辑，必须走样本外验证（沿用回测 OOS 纪律）

## 8. 风险与对策

| 风险 | 等级 | 对策 |
|------|------|------|
| 合规：digest/界面含「买入/卖出」动作词 | 高 | 措辞守「参考动作」+ 免责声明（复用 eval_track 文案） |
| 持仓数据缺失导致动作失真 | 中 | 未登记持仓默认未持仓；效果页/推送提示「按当前登记持仓派生」 |
| AI 成本失控（多时点 × 清单） | 中 | 默认 2 时点 + 盘中可选开关 + 规则快评降级 + ai_usage 监控 |
| 命中率统计失真（样本少） | 中 | 如实展示样本量；样本<30 的桶降级显示；免责声明 |
| 评估逻辑被历史结果误导（过拟合） | 中 | 优化建议走样本外验证，人工确认后应用 |
| 新入池信号滞后（20:00 生成） | 低 | 盘前推送覆盖昨日新入池；盘中时点不含当日新入池（如实标注） |
| 调度时点漂移/重复 | 低 | 过点拒绝 + 幂等（同 (日期,时段,股票) 不重复） |
| 推送渠道失败 | 低 | 发送结果可感知（成功/失败日志 + 重试） |

5. 界面：今日概览 / 当日多时点 / 历史记录 / 效果块 四块可用（AI 页子 Tab）
6. 历史记录：focus_evals 落库、跨重启保留、可查询

9. 合规：全站措辞不出现投顾式承诺
