二、API Key 鉴权

在「系统配置 → 开放 API」签发 Key 后，请求头携带：

Authorization: Bearer 你的API_KEY

Key 仅存哈希（Fernet 加密），限流按 Key 独立计数。

三、Webhook 事件与签名验证 (V4.0 M4)

事件触发时机
evaluate_doneAI 个股评估完成
review_ready每日市场复盘生成
anomaly_scan_done异动扫描完成
market_review_ready市场复盘就绪

每次投递带 X-Signature: sha256=<hex>（HMAC-SHA256，密钥为订阅时返回的 secret）。接收方验签示例：

import hmac, hashlib, json
body = json.dumps(payload, ensure_ascii=False).encode()  # 与投递体完全一致
expected = "sha256=" + hmac.new(SECRET.encode(), body, hashlib.sha256).hexdigest()
assert hmac.compare_digest(request.headers["X-Signature"], expected)

五、插件机制 (V4.0 M4)

backend/plugins/ 目录下的插件模块在启动时自动加载；插件导出 PLUGIN_META（名称/描述）与 register(ctx) 函数，可扩展数据源/通知/策略等能力（样例见仓库 backend/plugins/sample_plugin.py）。
